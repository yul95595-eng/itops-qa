# 工位网络端口故障报修与处理

## 一、适用范围  
本流程适用于公司办公区所有固定工位（含开放式工位、独立办公室、会议室固定信息点）的有线网络端口（RJ45接口）无法连接、速率异常、频繁断连等物理层及链路层故障的报修与处置。

---

## 二、常见故障现象与初步自检

| 故障现象 | 可能原因 | 自检建议 |
|----------|-----------|-----------|
| 网卡指示灯不亮（无Link） | 端口物理损坏、跳线未插紧、交换机端口关闭/故障、网线断裂 | ✅ 检查网线两端是否插牢；✅ 更换已知正常网线测试；✅ 尝试同一网线接入邻近可用端口对比 |
| 指示灯常亮但无法获取IP（无DHCP响应） | 交换机VLAN配置错误、端口被ACL限制、DHCP服务器异常 | ✅ `ipconfig /release && ipconfig /renew`（Windows）或 `sudo dhclient -r && sudo dhclient`（Linux/macOS）；✅ 查看是否分配到 `169.254.x.x`（APIPA地址），表明DHCP失败 |
| 能获取IP但无法访问内网资源（如OA、文件服务器） | 端口所属VLAN未接入对应业务网段、防火墙策略拦截、DNS异常 | ✅ `ping 10.10.1.1`（核心网关）验证三层连通性；✅ `nslookup oa.company.local` 测试DNS解析 |
| 高延迟、丢包、速率降为10Mbps | 网线质量差（非Cat5e/Cat6）、RJ45水晶头压接不良、端口协商异常 | ✅ 使用网线测试仪检测通断与线序；✅ 在系统网络适配器属性中强制设置速率为“100Mbps全双工”临时规避协商问题 |

> ⚠️ 注意：若自检后确认为物理端口问题（如插拔无反应、相邻端口均异常、墙面模块松动），请立即进入报修流程。

## 三、标准报修流程（ITSM系统）

### 1. 提交服务请求（SR）
- 登录公司ITSM自助服务平台（https://itsm.company.internal）  
- 选择服务目录：**网络与VPN → 工位网络端口故障**  
- 填写必填字段：
  - 工位编号（例：`B3-08F-217A`，位于工位铭牌左下角）  
  - 故障现象描述（需包含自检结果）  
  - 是否影响VPN接入（是/否）  
  - 附件上传：网卡状态截图（`ncpa.cpl` 中适配器状态页）、`ipconfig /all` 或 `ifconfig` 输出文本  

### 2. SLA响应时效
| 故障等级 | 定义 | 响应时间 | 解决时限 |
|----------|------|-----------|------------|
| P1（紧急） | 全工位断网、影响关键业务系统（如财务结算、生产MES） | ≤15分钟 | ≤2小时 |
| P2（高） | 单工位无网络且影响日常办公（邮件、OA、视频会议） | ≤30分钟 | ≤4工作小时 |
| P3（中） | 速率低于100Mbps、偶发丢包、仅影响非关键应用 | ≤2工作小时 | ≤1工作日 |

## 四、IT运维现场处理规范

### 处理步骤（按顺序执行）：
1. **定位物理链路**  
   - 核对工位编号，追踪墙面信息面板 → 水平线缆 → 配线架端口 → 接入交换机端口（记录交换机型号/IP及端口号，如 `SW-B3F-01: Gi1/0/23`）

2. **交换机侧检查**  
   - 登录交换机CLI，执行：  
     ```bash
     show interfaces status | include 1/0/23
     show mac address-table interface gigabitethernet 1/0/23
     show logging | include "Gi1/0/23"
     ```
   - 关键判断项：`notconnect`（物理未连）、`err-disabled`（端口因BPDU Guard/Loop Protect关闭）、`input errors > 0`（CRC错包）

3. **端口恢复操作**  
   - 若为 `err-disabled`：  
     ```bash
     configure terminal
     interface gigabitethernet 1/0/23
     shutdown
     no shutdown
     end
     ```
   - 若端口硬件故障或线缆测试失败：启用备用端口并更新配线架标签，同步在CMDB中更新端口状态为「已更换」。

4. **验证与闭环**  
   - 使用笔记本直连测试：`ping` 网关 + `nslookup` + 访问 `https://intranet.company.local`  
   - 在ITSM中更新处理记录，上传端口测试报告（含交换机`show`输出截图），将SR状态设为「已解决」。

## 五、附录：常见错误码参考

| 错误码 | 含义 | 应对措施 |
|--------|------|-----------|
| `ETH-PORT-ERR01` | 配线架至交换机跳线松动/氧化 | 重新拔插并用酒精棉片清洁金手指 |
| `ETH-PORT-ERR07` | 水平线缆长度超90米或串扰超标 | 更换整条六类线，避免与强电同槽敷设 |
| `ETH-PORT-ERR12` | 墙面信息面板RJ45模块接触不良 | 更换面板模块（型号：AMP/Tyco Cat6A Keystone） |
| `SW-PORT-DOWN-204` | 接入交换机端口光模块故障（仅万兆上联口） | 替换SFP+模块，检查对端光功率（需≥-12dBm） |
