# 堡垒机登录与远程运维通道说明

## 一、概述  
堡垒机（Jump Server）是公司统一的运维安全审计平台，所有对生产环境服务器、网络设备及数据库的远程访问均须通过堡垒机进行。本说明适用于运维人员、开发人员及第三方技术支持人员，涵盖登录方式、权限申请、连接流程及常见问题处理。

## 二、适用场景  
- Linux/Windows 服务器 SSH/RDP 远程管理  
- 网络设备（防火墙、交换机、路由器）CLI 访问  
- Oracle/MySQL/SQL Server 数据库 Web 或客户端连接  
- 审计日志留存与操作回溯  

## 三、登录方式与认证机制  

### 3.1 支持的登录入口  
| 入口类型 | 访问地址 | 协议/端口 | 说明 |
|----------|-----------|------------|------|
| Web 控制台 | `https://bastion.company.com` | HTTPS/443 | 图形化界面，支持文件上传、会话审计、命令白名单控制 |
| SSH 直连 | `ssh -p 2222 user@bastion.company.com` | SSH/2222 | 用于脚本调用或 CLI 批量操作（需提前配置密钥） |
| RDP 代理 | `mstsc /v:bastion.company.com:3389` | RDP/3389 | 自动跳转至目标 Windows 主机（需启用“RDP 代理模式”） |

### 3.2 身份认证要求  
- **双因素认证（2FA）**：首次登录需绑定企业微信/短信验证码；后续登录每次均需输入动态令牌（TOTP）或扫码确认。  
- **账号来源**：统一使用公司 AD 域账号（格式：`COMPANY\username`），禁止使用本地账号或共享账号。  
- **密码策略**：AD 密码有效期 90 天，堡垒机同步 AD 密码策略，不单独维护密码。

## 四、远程运维标准流程  

### 4.1 权限申请（必需前置步骤）  
1. 登录公司 ITSM 系统 → 提交「堡垒机资源访问申请」工单；  
2. 填写目标资产 IP/主机名、操作系统、所需协议（SSH/RDP/DB）、最小权限范围（如仅读取、仅重启服务）；  
3. 经直属主管 + 运维安全组双审批通过后，自动同步权限至堡垒机（通常 ≤ 15 分钟）；  
4. 登录堡垒机 Web 控制台 → 「我的资产」中确认目标设备已显示且状态为「已授权」。

### 4.2 建立远程连接（以 Linux 服务器为例）  
1. 使用 Chrome/Firefox 访问 `https://bastion.company.com`，输入 AD 账号及 2FA 验证；  
2. 在「资产列表」中搜索目标服务器（支持 IP、主机名、标签模糊匹配）；  
3. 点击目标条目右侧「Web SSH」按钮，系统自动建立加密隧道；  
4. 首次连接将提示校验服务器 SSH 指纹（SHA256: `xx:xx:xx...`），确认后输入目标服务器的登录凭证（支持密钥或密码）；  
5. 连接成功后，所有命令、输入、输出实时记录于审计日志，不可关闭或绕过。

## 五、常见错误与处理  

| 错误现象 | 可能原因 | 解决方案 |
|----------|-----------|-----------|
| `Connection refused (port 2222)` | 堡垒机服务异常或本地防火墙拦截 | 检查 `telnet bastion.company.com 2222` 是否可达；联系网络组确认出口策略放行 TCP/2222 |
| `Authentication failed` | AD 密码过期 / 2FA 设备未同步 / 账号未授权 | 重置 AD 密码；在「堡垒机个人中心 → 安全设置」重新绑定 TOTP；核查 ITSM 工单审批状态 |
| `No route to host`（RDP 场景） | 目标 Windows 主机未开启远程桌面 / 防火墙阻止 3389 | 登录堡垒机 Web 控制台 → 查看该资产详情页的「连通性检测」结果；联系服务器管理员确认 `winrm quickconfig` 及防火墙规则 |
| `Session timeout after 10min` | 空闲超时策略触发（默认 600 秒） | Web 界面右上角点击「保持活跃」；或在 SSH 连接时添加参数：`ssh -o ServerAliveInterval=60 -p 2222 user@bastion.company.com` |

## 六、安全与合规要求  
- ❗ 禁止将堡垒机账号密码透露给他人，禁止使用自动化工具绕过审计（如直接 `ssh user@target`）；  
- ❗ 所有高危操作（如 `rm -rf`、`DROP DATABASE`、`reboot`）需在工单中明确说明原因并获审批；  
- ✅ 审计日志保留 ≥ 180 天，支持按时间、用户、IP、命令关键词检索；  
- ✅ 每季度开展一次堡垒机权限复核，清理离职/转岗人员访问权限。

> 📌 **附：紧急通道说明**  
> 如遇堡垒机整体不可用（如 `503 Service Unavailable` 持续 > 5 分钟），可启用备用 VPN+跳板机方案：  
> 1. 连接公司 SSL VPN（`vpn.company.com`，证书认证）；  
> 2. SSH 至跳板机 `jump01.internal.company.com`（仅限运维组预授权 IP）；  
> 3. 从跳板机发起目标连接（**该通道无完整审计能力，仅限应急，使用后 2 小时内需补提审计说明工单**）。
