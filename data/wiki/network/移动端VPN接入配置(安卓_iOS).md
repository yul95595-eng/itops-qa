# 移动端VPN接入配置（Android / iOS）

> **适用对象**：公司全体员工  
> **最后更新**：2024年6月15日  
> **文档版本**：v2.3  
> **关联策略**：《公司远程访问安全规范 V3.1》《移动设备管理（MDM）实施指南》

## 一、前置条件与准入要求

### 1.1 设备合规性要求
| 项目 | Android 要求 | iOS 要求 |
|------|--------------|----------|
| 最低系统版本 | Android 8.0（API Level 26）及以上 | iOS 14.0 及以上 |
| 设备状态 | 已启用「开发者选项」非必需；**禁止Root/越狱** | **必须未越狱**；需开启「设备管理」（如已部署MDM） |
| 网络环境 | 支持 IPv4 或双栈网络，DNS 可解析 `vpn.company.com` | 同左，建议关闭「无线局域网助理」以防自动切换蜂窝网络 |
| 应用依赖 | 无需额外客户端（系统原生支持IKEv2/IPsec或OpenVPN） | 同左；若使用第三方协议（如WireGuard），需安装官方App |

> ⚠️ **不满足任一条件将导致连接失败或被安全网关拒绝（错误码 `ERR_AUTH_DEVICE_UNTRUSTED`）**

## 二、标准接入方式（推荐：IKEv2 + EAP-TLS）

公司统一采用 **IKEv2 over IPsec** 协议，结合证书双向认证（EAP-TLS），兼顾安全性与移动端兼容性。

### 2.1 配置前准备

1. 登录公司统一身份门户（https://idp.company.com） → 进入「移动VPN服务」模块  
2. 下载以下3个文件（有效期90天，到期前7天邮件提醒）：
   - `company-root-ca.crt`（根证书）
   - `user-cert.p12`（含私钥的用户证书，密码由SSO二次验证后动态生成）
   - `vpn-profile.mobileconfig`（iOS专用配置描述文件）或 `vpn-config.xml`（Android ADB导入用）

> 🔐 所有证书均绑定员工工号与设备指纹，**禁止导出、截图或跨设备复用**

## 三、分平台配置步骤

### 3.1 Android 配置（原生设置，无需第三方App）

> ✅ 适配品牌：Samsung One UI / Xiaomi MIUI / Huawei EMUI / 原生Android  
> ❌ 不支持：部分定制ROM（如ColorOS旧版）可能需手动启用「高级VPN选项」

#### 操作流程：
1. **安装证书**  
   - 设置 → 安全 → 加密与凭据 → 从存储设备安装 → 选择 `company-root-ca.crt` 和 `user-cert.p12`  
   - 输入SSO动态密码完成安装（证书别名显示为 `COMPANY-USER-[工号后4位]`）

2. **新建VPN连接**  
   - 设置 → 网络和互联网 → VPN → 添加VPN（+）  
   - 填写如下参数：
     | 字段 | 值 |
     |------|----|
     | 名称 | `COMPANY-IKEv2-SECURE` |
     | 类型 | `IKEv2 EAP（证书）` |
     | 服务器地址 | `vpn.company.com` |
     | 身份验证 | `EAP-TLS` |
     | 用户证书 | `COMPANY-USER-[工号后4位]`（下拉选择） |
     | CA证书 | `company-root-ca`（下拉选择） |
     | 高级选项 → 「始终开启VPN」✅、「阻止不受信任的证书」✅ |

3. **连接测试**  
   - 返回VPN列表 → 点击刚创建的条目 → 输入当前设备锁屏密码（非工号密码）  
   - 成功后状态栏显示「钥匙图标」，通知栏提示「已连接至 COMPANY-IKEv2-SECURE」

> 💡 **常见问题排查**  
> - 错误码 `ERR_IKEV2_AUTH_FAILED`：检查P12证书是否安装成功、时间是否同步（NTP需开启）  
> - 连接后无法访问内网：确认DNS设置为 `10.100.1.10`（在VPN高级设置中强制指定）

---

### 3.2 iOS 配置（推荐使用 `.mobileconfig` 描述文件）

> ✅ 兼容 iOS 14–17；需通过Safari浏览器安装（邮件附件或扫码下载无效）

#### 操作流程：
1. 使用 **iPhone/iPad 自带 Safari** 打开 `vpn-profile.mobileconfig` 下载链接  
2. 系统弹出「描述文件已下载」→ 点击右上角「安装」→ 输入设备锁屏密码  
3. 安装完成后进入：  
   **设置 → 已下载的描述文件 → 安装 → 输入密码 → 重启设备（首次必做）**  
4. 重启后生效：  
   - 设置 → 通用 → VPN与设备管理 → 查看 `COMPANY-IKEv2-SECURE` 配置  
   - 开关开启即连接；可设置「连接时发送诊断日志」用于IT支持（默认关闭）

> 📌 **关键提示**  
> - 若安装后无VPN条目：检查「屏幕使用时间」→「内容与隐私限制」→「允许更改VPN设置」是否启用  
> - 错误码 `NEVPNConnectionStatusCodeInvalidCertificate`：重装根证书（先删除旧证书再重装）

## 四、故障速查表

| 现象 | 可能原因 | 解决方案 |
|------|-----------|------------|
| 连接后立即断开 | 设备时间偏差 >3分钟 | 设置 → 通用 → 日期与时间 → 开启「自动设置」 |
| 提示“身份验证失败” | P12证书密码输入错误（非SSO密码） | 重新下载 `user-cert.p12`，注意密码为「SSO二次验证后页面显示的6位动态码」 |
| 内网域名无法解析（如 `intranet.company.com`） | DNS未指向内网DNS服务器 | Android：在VPN高级设置中手动填入 `10.100.1.10`；iOS：联系IT添加DNS配置项 |
| iOS安装`.mobileconfig`无响应 | 使用Chrome/Firefox等第三方浏览器 | **必须使用Safari**，且确保「阻止跨站跟踪」未开启 |
