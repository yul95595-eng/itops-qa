# 域账号解锁与密码重置 SOP（标准操作流程）

**适用范围**：公司所有使用 Active Directory（AD）域环境的员工账号（含 Windows 登录、Outlook 邮箱、OA 系统等集成认证场景）  
**责任角色**：IT 服务台工程师、域管理员  
**生效日期**：2024-06-01  
**版本号**：v2.3  

---

## 一、适用场景说明

以下情况需执行本 SOP：

| 场景类型 | 典型表现 | 是否需验证身份 |
|----------|----------|----------------|
| 账号被锁定（Account Locked Out） | 用户登录 Windows/VPN/OA 提示“您的账户已被锁定”；AD 用户属性中 `LockoutTime` 非零值 | ✅ 是（需工单+本人语音/企业微信视频核验） |
| 密码遗忘（Forgot Password） | 登录提示“用户名或密码错误”，且已尝试 5 次以上失败导致潜在锁定风险 | ✅ 是（同上） |
| 密码过期强制重置失败 | 登录时提示“密码已过期，请联系管理员”，但自助重置门户不可用或用户未注册 | ✅ 是 |
| 批量异常锁定（>3人同时报锁） | 可能为暴力破解、共享设备误操作或组策略变更引发，需同步排查安全事件 | ✅ 是（升级至信息安全组协同处置） |

> ⚠️ 注意：  
> - **禁止**通过禁用再启用账号方式“解锁”——将重置 `pwdLastSet` 并触发强制改密，影响邮箱自动连接及单点登录（SSO）会话；  
> - **禁止**在非域控服务器（如文件服务器、应用服务器）上执行解锁操作——必须通过域控制器或经批准的管理跳板机。

## 二、操作前必备检查

请按顺序确认以下项，任一不满足则中止流程并记录原因：

1. ✅ 用户已提交有效 IT 服务请求（工单号格式：ITSR-YYYYMMDD-XXXXX）；  
2. ✅ 工单中已填写：员工姓名、工号、部门、常用登录设备 IP/MAC（用于溯源）；  
3. ✅ 通过企业微信/电话完成身份核验（需复述入职日期+直属主管姓名，或提供身份证后4位）；  
4. ✅ 确认目标账号存在于生产域 `corp.company.local`（非测试域 `test.company.local`）；  
5. ✅ 检查 AD 复制状态（运行 `repadmin /replsummary`），确保所有域控同步延迟 < 15 秒。

## 三、标准操作步骤（AD 管理中心 GUI 方式）

### 步骤 1：定位目标用户对象
- 登录域控服务器（`DC01.corp.company.local`）或管理工作站（已安装 RSAT-ADDS）；  
- 打开 **Active Directory 用户和计算机（ADUC）** → 连接到 `corp.company.local`；  
- 在「Users」容器或对应 OU（如 `OU=Finance,DC=corp,DC=company,DC=local`）中搜索用户 `sAMAccountName`（非显示名）；  
- 右键用户 → **属性** → 切换至 **“账户”** 选项卡。

### 步骤 2：判断并执行对应操作

| 当前状态 | 操作动作 | 关键参数设置 |
|----------|----------|--------------|
| `账户已锁定`（勾选“账户已锁定”） | 点击 **“解锁账户”** 按钮 | 无需修改其他字段 |
| `密码过期` 或 `需重置密码` | 勾选 **“用户必须在下次登录时更改密码”**<br>点击 **“重设密码”** → 输入新密码（符合公司策略：≥12位，含大小写字母+数字+特殊字符，无字典词） | ❗ 新密码**不得**与近5次密码重复（AD 默认 `PasswordHistorySize=5`） |
| `账户已禁用`（非锁定） | 取消勾选 **“账户已禁用”** → 应用 | 同步检查 `msDS-User-Account-Control-Computed` 属性是否含 `0x2`（禁用标志） |

### 步骤 3：验证与收尾
1. 点击 **“确定”** 保存属性变更；  
2. 立即在另一台客户端执行验证：  
   ```powershell
   # PowerShell 验证（以域管理员身份运行）
   Get-ADUser username -Properties LockedOut,PasswordExpired,Enabled | 
     Select-Object Name,LockedOut,PasswordExpired,Enabled,LastLogonDate
   ```  
3. 向用户发送标准化通知邮件（模板见附录 A）；  
4. 在工单系统中标记为「已解决」，关闭工单；  
5. **日志归档**：截图 ADUC 操作界面 + `Get-ADUser` 输出结果，存入工单附件。

## 四、常见错误与处理

| 错误现象 | 可能原因 | 解决方案 |
|----------|----------|----------|
| “无法解锁账户：拒绝访问” | 当前登录账号无 `Reset Password` 或 `Unlock Account` 权限 | 使用 `Domain Admins` 组成员账号操作；检查用户所在 OU 的委派控制权限 |
| 重置后仍提示“密码过期” | 客户端缓存 Kerberos TGT 或本地凭据管理器（Windows Credential Manager）残留旧凭据 | 指导用户运行 `klist purge` + 清空凭证管理器中 `corp.company.local` 相关条目 |
| Outlook 提示“无法连接到 Exchange” | 密码重置后未同步至 Exchange Online（混合部署场景） | 手动触发 Azure AD Connect 增量同步：<br>`Start-ADSyncSyncCycle -PolicyType Delta` |
| 解锁后 1 分钟内再次被锁 | 存在后台服务/映射驱动器/移动设备仍在使用旧凭据自动重连 | 检查 `Security Event Log` 中 `Event ID 4740`（锁定事件）的 `Caller Computer Name`，通知用户关闭相关设备或服务 |
