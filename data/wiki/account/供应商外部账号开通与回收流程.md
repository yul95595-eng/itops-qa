# 供应商外部账号开通与回收流程

> **适用范围**：适用于公司为第三方供应商（含外包人员、驻场支持、系统集成商等）开通/回收企业内部系统访问账号（如 AD 域账号、OA、ERP、ITSM、VPN、云平台 IAM 子用户等）的标准化操作流程。  
> **责任主体**：IT 运维部账号管理组牵头，采购部、业务部门、供应商对接人协同执行。

---

## 一、账号开通流程

### 1. 前置条件确认

| 条件项 | 要求说明 | 验证方式 |
|--------|----------|----------|
| ✅ 采购合同/服务协议已签署并生效 | 合同中需明确服务范围、人员清单、保密条款及账号使用授权 | 提交合同扫描件（含签字页）至 IT 服务台工单附件 |
| ✅ 《供应商账号申请表》完整填写 | 包含：供应商全称、申请人姓名/身份证号、岗位/角色、所需系统列表、权限等级（只读/操作/管理员）、预计使用周期 | 在 [ITSM 服务门户 → 账号管理 → 外部账号申请] 提交电子表单 |
| ✅ 业务部门负责人审批通过 | 审批意见需明确“同意开通”及必要性说明 | 系统内电子签批或邮件确认（需含工单编号） |
| ✅ 供应商完成《信息安全承诺书》签署 | 使用公司统一模板（V3.2），加盖供应商公章 | 扫描件上传至工单附件，有效期≥账号使用期 |

> ⚠️ **注意**：缺少任一前置条件，IT 运维部有权拒绝受理；严禁“先开通、后补材料”。

### 2. 开通执行步骤（IT 运维部操作）

1. **工单受理与合规校验**  
   - 登录 ITSM 工单系统，核对申请信息完整性、合同有效期、审批链完整性；
   - 检查申请人是否已在公司「外部人员白名单库」备案（防重复/冒用）。

2. **账号创建与权限配置**  
   - 在 AD 域中创建格式为 `SUP-<供应商缩写>-<工号>` 的安全组账号（例：`SUP-ABC-2024001`）；  
   - 依据《供应商最小权限矩阵表》（见附录A），为该账号分配对应系统角色（如：`ERP_Vendor_ReadOnly`、`VPN_TeamA_Access`）；  
   - **禁止直接授予 Domain Admin / root / Administrator 等高危权限**。

3. **密码与首次登录设置**  
   - 自动生成强密码（12位+大小写字母+数字+特殊字符），通过加密邮件一次性发送至供应商对接人预留邮箱；  
   - 强制首次登录时修改密码，并启用 MFA（短信/微软 Authenticator 二选一）。

4. **通知与归档**  
   - 向申请人、业务部门接口人、采购专员发送开通完成通知（含账号、初始权限、系统访问入口、密码重置路径）；  
   - 更新《外部账号台账》（Excel + SharePoint 双备份），记录开通时间、有效期、到期提醒日期。

## 二、账号回收流程

### 1. 触发场景（满足任一即启动回收）

- 合同/服务协议到期且未续签；
- 供应商人员离职、调岗或终止驻场；
- 业务部门提出权限降级或账号停用申请；
- 安全审计发现异常登录行为（如：连续3次失败登录、非工作时间高频操作、异地IP访问等）。

### 2. 回收执行步骤

1. **发起回收申请**  
   - 由业务部门或采购部在 ITSM 提交「外部账号回收工单」，注明原因、涉及账号、期望截止时间（TTL）。

2. **IT 运维部核查与冻结**  
   - 核对合同状态、最后登录日志（AD/VPN/ERP 等系统）、MFA 绑定设备变更记录；  
   - **立即执行临时冻结**（禁用账号、撤销所有系统 Token、注销活跃会话）—— *冻结后2小时内完成*。

3. **正式注销与清理**  
   - 72 小时内完成以下操作：  
     - 删除 AD 域账号（保留回收日志 ≥180 天）；  
     -  bereinigen（清理）所有关联权限组成员关系；  
     - 清空邮箱归档（保留6个月备查，按《数据保留策略 V2.1》执行）；  
     - 从 VPN 白名单、云平台 IAM、堡垒机授权列表中移除。

4. **闭环确认**  
   - 向申请人、业务方、采购方发送《账号回收完成确认函》（含操作时间戳、操作人、系统清单）；  
   - 更新《外部账号台账》，标记状态为「已注销」，同步触发自动归档。

## 三、常见问题与错误码处理

| 错误码 | 场景描述 | 解决方案 |
|---------|-----------|------------|
| `ERR-SUP-401` | 申请表中供应商名称与合同主体不一致 | 要求采购部提供《主体一致性说明函》并盖章 |
| `ERR-SUP-403` | 同一身份证号在系统中已存在有效账号 | 查询历史工单，确认是否为同一人跨项目复用；若否，需供应商出具《身份唯一性声明》 |
| `ERR-SUP-500` | 权限配置失败（如角色不存在/策略冲突） | 检查《最小权限矩阵表》版本，联系 IAM 策略管理员同步更新角色定义 |
| `ERR-SUP-503` | 邮箱发送失败（供应商邮箱拒收/域名屏蔽） | 改用加密 PDF 附件通过业务部门转交，并记录替代交付方式 |
