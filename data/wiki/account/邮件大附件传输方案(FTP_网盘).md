# 邮件大附件传输方案（FTP/网盘）

## 概述  
公司邮箱系统对单封邮件附件大小限制为 **25 MB**（含正文与所有附件总和），超出该限制的文件无法通过常规 SMTP 方式发送。为保障业务协作中大文件（如设计源稿、视频素材、数据库备份等）的安全、可靠、可追溯传输，IT 运维部制定本《邮件大附件传输方案》，明确推荐使用 **企业级 FTP 服务** 或 **合规网盘服务** 作为替代传输通道，并规范操作流程与安全要求。

---

## 适用场景

| 场景类型 | 典型文件示例 | 推荐方式 | 说明 |
|----------|--------------|-----------|------|
| 内部跨部门协作（≤500 MB） | PSD/AE 工程文件、高清渲染序列帧 | 企业网盘（OneDrive for Business / 腾讯微云企业版） | 支持权限分级、操作留痕、自动同步 |
| 对外客户交付（≥500 MB，需临时访问） | 产品演示视频（2 GB）、固件包（1.2 GB） | 公司统一 FTP 服务（`ftp.corp.example.com`） | 提供带时效的下载链接，支持断点续传与传输日志审计 |
| 敏感数据交换（含PII/PCI信息） | 加密财务报表、用户脱敏数据集 | **禁用公网网盘**，仅限内网 FTP + SSL 加密通道 | 必须启用 `FTPS`（FTP over TLS）或 `SFTP` 协议 |

> ⚠️ **禁止行为**：  
> - 使用个人网盘（如百度网盘、iCloud）分享公司业务文件；  
> - 将密码明文写入邮件正文或附件；  
> - 通过压缩包分卷绕过附件限制（违反《公司数据安全管理办法》第4.2条）。

## 标准操作流程（以 FTP 方式为例）

### 1. 上传文件至公司 FTP 服务器
1. 打开 FTP 客户端（推荐：FileZilla Client / WinSCP / Cyberduck）；  
2. 连接地址：`ftp.corp.example.com`，端口：`21`（FTPS）或 `22`（SFTP）；  
3. 认证方式：使用 **AD 域账号 + 当前邮箱密码**（首次登录需通过 MFA 验证）；  
4. 上传目标路径：`/outgoing/{发件人邮箱前缀}/{YYYYMMDD}_{项目简称}/`（例：`/outgoing/zhangsan/20240520_MarketingVideo/`）；  
5. 上传完成后，记录生成的 **唯一访问链接**（格式：`https://ftp.corp.example.com/dl?token=abc123xyz&exp=1716220800`）及有效期（默认 **72 小时**）。

### 2. 邮件中发送访问指引
- **邮件主题**：`【大附件】{项目名称} - 请查收FTP下载链接`  
- **正文中必须包含以下结构化信息**：

```text
📁 文件信息：
  • 总大小：2.1 GB  
  • 文件列表：demo_4K.mp4（1.8 GB）、README.pdf（124 KB）  
  • 上传时间：2024-05-20 14:32（UTC+8）

🔗 下载链接（72小时内有效）：
  https://ftp.corp.example.com/dl?token=abc123xyz&exp=1716220800

🔒 安全提示：
  • 本链接仅限指定收件人访问，不可转发；
  • 如遇“Invalid token”错误，请检查链接是否过期或联系 IT 支持（helpdesk@corp.example.com）；
  • 建议使用 Chrome/Firefox 浏览器打开，避免 IE 兼容模式。
```

## 常见问题与错误码处理

| 错误现象 | 可能原因 | 解决方案 |
|----------|-----------|------------|
| `530 Login authentication failed` | MFA 未通过或密码过期 | 登录 [SSO 门户](https://sso.corp.example.com) 更新密码并完成二次验证 |
| `550 Permission denied` | 目标目录无写入权限（非本人命名空间） | 检查路径是否符合 `/outgoing/{your_email_prefix}/...` 规则；勿尝试上传至 `/incoming/` 等受控目录 |
| `Download link expired or invalid` | Token 过期 / 链接被手动撤销 / IP 异常触发风控 | 联系 IT 运维组重生成链接（提供原始上传时间与文件哈希值） |
| `ERR_CONNECTION_TIMED_OUT`（浏览器） | 客户端网络策略拦截 HTTPS FTP 下载页 | 建议改用 FTP 客户端直连（协议 `sftp://ftp.corp.example.com`）或联系本地 IT 开放白名单 |

## 合规与审计要求

- 所有 FTP/SFTP 上传行为均记录于 **SIEM 平台（Splunk）**，保留日志 ≥180 天；  
- 网盘共享链接须开启「仅登录用户可访问」+「禁止下载原始文件」（针对敏感文档）；  
- 每季度由信息安全部抽样审计大附件传输记录，重点核查：  
  - 是否存在超期未清理的 `/outgoing/` 子目录；  
  - 是否向非授权邮箱域（如 `@gmail.com`）发放无密码保护链接；  
  - 是否出现同一账号高频次（>20 次/日）上传 >1GB 文件行为（疑似数据泄露风险）。
