# 移动设备邮箱配置（Outlook/手机）  
**所属知识域：账号与邮箱**  
*最后更新时间：2024年6月15日*  
*适用对象：公司全体员工（含外包人员）*

---

## 一、适用范围

本指南适用于在 iOS（iPhone/iPad）及 Android 设备上，通过 **Microsoft Outlook 官方 App** 或系统原生邮件客户端配置公司企业邮箱（基于 Microsoft Exchange Online / Office 365）的操作。  
✅ 支持协议：Exchange ActiveSync（EAS）或 Modern Authentication（推荐）  
❌ 不支持：POP3/IMAP 方式登录（因安全策略限制，已禁用）

> ⚠️ 注意：公司邮箱账户需已启用 MFA（多因素认证），且用户已完成 [Azure AD 自助注册](https://myaccount.microsoft.com)。

---

## 二、前置条件检查

请确保满足以下全部条件：

| 检查项 | 要求 | 验证方式 |
|--------|------|-----------|
| ✅ 设备系统版本 | iOS ≥ 15.0；Android ≥ 10.0 | 「设置」→「通用」或「关于手机」查看版本号 |
| ✅ Outlook App 版本 | ≥ 4.2500（iOS）或 ≥ 4.2500.0（Android） | App Store / 华为应用市场搜索“Microsoft Outlook”，查看当前版本 |
| ✅ 网络环境 | 可访问公网及公司 Azure AD 登录页（`https://login.microsoftonline.com`） | 尝试在浏览器中打开该地址，应显示 Microsoft 登录界面 |
| ✅ 账户状态 | 邮箱已激活、未被锁定、MFA 已绑定 | 登录 [Office 365 Portal](https://portal.office.com) 验证收发功能正常 |

## 三、配置步骤（以 Outlook App 为主流方式）

### 3.1 iOS 设备（iPhone/iPad）配置流程

1. **安装并启动 Outlook App**  
   - 从 App Store 下载最新版 Microsoft Outlook，安装后打开。

2. **添加账户**  
   - 点击右下角「设置」图标（⚙️）→「添加账户」→「Exchange」  
   - 输入完整公司邮箱地址（如：`zhang.san@company.com`），点击「继续」

3. **身份验证（Modern Auth）**  
   - 自动跳转至 Microsoft 登录页 → 输入密码 → 触发 MFA（短信/微软验证器/电话呼叫）  
   - ✅ 成功后返回 Outlook，自动同步邮箱、日历、联系人（默认开启）

4. **权限授权（首次运行关键步骤）**  
   - 系统弹出「允许 Outlook 访问」提示时，请务必勾选：  
     - ☑️ 邮件  
     - ☑️ 日历  
     - ☑️ 联系人  
     - ☑️ 提醒通知（建议开启）  
   - 点击「好」完成授权

5. **验证同步状态**  
   - 返回主界面，下拉刷新收件箱，确认可见最近 30 天邮件  
   - 进入「日历」Tab，检查是否同步公司会议邀请

> 🔍 常见错误码参考：  
> - `0x80072F0D`：证书不可信 → 清除 Safari 浏览器历史记录 + 重启设备后重试  
> - `0x80072EE7`：网络连接失败 → 切换 Wi-Fi/蜂窝网络，关闭 VPN 后重试  

---

### 3.2 Android 设备配置流程（Outlook App）

1. 打开 Outlook App → 点击左上角「☰」→「设置」→「添加账户」→「Exchange」

2. 输入邮箱地址 → 点击「连接」

3. 在 Microsoft 登录页完成账号密码输入及 MFA 验证（同 iOS 步骤）

4. 授权权限（Android 会分步请求）：  
   - 允许「存储」（用于附件下载）  
   - 允许「通知」（邮件提醒）  
   - 允许「日历」和「联系人」（如需同步）

5. 设置同步选项（可选）：  
   - 进入「设置」→「账户」→「你的邮箱」→「同步设置」  
   - 建议配置：  
     - 同步天数：`30 天`（平衡性能与容量）  
     - 同步内容：邮件 ✔️｜日历 ✔️｜联系人 ✔️｜任务 ❌（非必需）

## 四、故障排查速查表

| 现象 | 可能原因 | 解决方案 |
|------|----------|-----------|
| 添加账户时提示“无法连接到服务器” | 设备时间不准确 | 设置 → 通用 → 日期与时间 → 开启「自动设置」 |
| 邮件同步中断/延迟 > 15 分钟 | 后台进程被省电模式限制 | 设置 → 电池 → 应用启动管理 → 关闭 Outlook 的「自动管理」，手动允许后台运行 |
| MFA 验证后仍反复要求登录 | Outlook 缓存凭证异常 | 设置 → 账户 → 删除该账户 → 重启 App → 重新添加 |
| 日历事件不显示或无提醒 | 系统日历未授予 Outlook 权限 | Android：设置 → 应用 → Outlook → 权限 → 开启「日历」；iOS：设置 → Outlook → 开启「日历」 |

---

## 五、安全与合规说明

- 所有移动设备配置必须启用 **设备加密**（iOS：已默认启用；Android：需在「设置 → 安全 → 加密」中开启）  
- 离职/转岗员工的邮箱账户将在 HR 流程完成后 **2 小时内远程擦除**（通过 Intune MDM 策略）  
- 禁止使用第三方邮件客户端（如 Spark、BlueMail）配置公司邮箱（存在凭证明文存储风险）
