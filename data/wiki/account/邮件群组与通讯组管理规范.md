# 邮件群组与通讯组管理规范

## 1. 概述  
本规范适用于公司内部所有基于 Microsoft Exchange Online（Microsoft 365）及本地 Exchange Server 部署的邮件群组（Mail-enabled Groups）与通讯组（Distribution Groups）的创建、维护、权限控制与生命周期管理。旨在保障信息传递安全、提升协作效率、满足合规审计要求，并避免因配置不当导致的邮件投递失败、权限越界或数据泄露风险。

---

## 2. 术语定义

| 术语 | 定义 | 适用场景 |
|------|------|----------|
| **通讯组（Distribution Group）** | 仅用于邮件分发的静态/动态成员集合，无共享邮箱、无协作功能，不可登录或拥有安全标识符（SID） | 内部通知类邮件（如：全员公告、部门简报） |
| **邮件群组（Mail-enabled Security Group）** | 兼具邮件分发与 Active Directory 安全权限分配能力的组，具有 SID，可授予文件服务器、SharePoint 等资源访问权限 | 需同时实现“收邮件”+“控权限”的场景（如：IT运维组、财务审批组） |
| **Microsoft 365 组（Unified Group）** | 基于云的现代协作组，自动绑定共享邮箱、OneDrive、SharePoint 站点、Planner 等资源 | 跨部门项目协作、临时工作组 |
| **动态通讯组（Dynamic Distribution Group）** | 成员资格基于 AD 属性（如 Department、Title、CustomAttribute）实时计算，无需手动维护成员 | 大型组织按属性自动归集（如：“所有北京办公的高级工程师”） |

> ⚠️ 注意：Exchange Online 中已**不再支持新建传统通讯组（Legacy Distribution Group）**，新组应优先选用 Microsoft 365 组或邮件启用的安全组。

## 3. 创建与配置规范

### 3.1 创建原则
- ✅ **最小权限原则**：仅授予必要成员，禁止使用 `Everyone`、`All Users` 或通配符邮箱。
- ✅ **命名规范**（统一前缀 + 业务域 + 用途）：
  - `dg-<domain>-<purpose>`：如 `dg-finance-monthly-report`
  - `sg-<domain>-<purpose>`：如 `sg-it-admin-access`
  - `m365-<project>-<role>`：如 `m365-proj-ai-reviewers`
- ✅ **描述字段必填**：明确说明用途、负责人、有效期（如适用）、关联流程（如：ISO27001 控制项 A.9.2.3）。
- ❌ 禁止使用中文、空格、特殊字符（`/ \ [ ] : ; | = , + * ? < >`）。

### 3.2 创建流程（Exchange Online / Microsoft 365 后台）

1. 登录 [Microsoft 365 Admin Center](https://admin.microsoft.com) → **Groups** → **Active groups** → **Create a group**；
2. 选择组类型：
   - 日常协作 → 选 **Microsoft 365 group**；
   - 权限+邮件双需求 → 选 **Security group** → 勾选 *Mail-enable this group*；
   - 纯邮件广播（无权限需求）→ 选 **Distribution group**（仅限存量维护，新场景不推荐）；
3. 填写名称、描述、隐私设置（**建议设为“Private”**，防止未授权成员发现和请求加入）；
4. 设置成员：手动添加或通过动态规则（需 PowerShell 配置）；
5. （仅安全组）在 Azure AD 中为该组分配应用/资源权限（如 SharePoint 站点权限、Teams 团队所有权）；
6. 记录至《邮件组资产登记表》（见第5节）。

> 🔑 关键配置项检查清单：
> - [ ] 邮箱地址格式为 `groupname@company.com`（符合公司域名策略）  
> - [ ] “允许向组发送邮件”设置为 `Only senders inside my organization`（禁用外部投递，除非明确业务需要并经信息安全审批）  
> - [ ] “允许未认证发件人发送” → **必须关闭**（防范邮件伪造）  
> - [ ] 启用邮件审核日志（默认开启，确认 `Set-UnifiedGroup -Identity "xxx" -AuditEnabled $true`）

## 4. 运维与安全要求

### 4.1 成员管理
- 成员变更须由组所有者或 IT 运维团队操作，**禁止自助加组/退组**（Microsoft 365 组除外，但需开启审批流）；
- 离职员工须在 HR 流程触发后 **24 小时内** 从所有群组中移除；
- 每季度执行一次成员清理审计（脚本示例见附录 A）。

### 4.2 权限与审计
- 所有邮件启用的安全组（sg-*）必须在 Azure AD 中明确分配至少一项资源权限，否则降级为通讯组；
- 每半年导出组成员及权限报告，提交至信息安全管理部备案；
- 异常行为监控项：
  - 单日邮件接收量突增 >5000 封（疑似被滥用为中继）；
  - 非工作时间（22:00–06:00）高频发送记录；
  - 收件人包含大量外部域名（`@gmail.com`, `@163.com` 等）且无白名单审批。

### 4.3 常见错误码与处置

| 错误码 | 场景 | 排查与修复 |
|--------|------|-------------|
| `550 5.7.131` | 发件人无权向组发送邮件（权限拒绝） | 检查组设置中 *Who can send mail to this group*；确认发件人是否在允许列表或属组织内 |
| `550 5.1.10` | 收件人地址不存在（组已删除或邮箱禁用） | 使用 `Get-UnifiedGroup -Identity "xxx"` 验证组状态；检查 `HiddenFromAddressListsEnabled` 是否为 `$true` |
| `554 5.2.190` | 动态组解析失败（AD 属性值异常或为空） | 运行 `Get-DynamicDistributionGroup "xxx" \| fl RecipientFilter`，验证 LDAP 过滤器语法与目标用户属性值 |

## 5. 资产登记与生命周期管理

所有邮件群组/通讯组须纳入公司 IT 资产台账，登记字段包括：

| 字段名 | 示例值 | 必填 | 说明 |
|--------|--------|------|------|
| 组ID | `sg-hr-compensation-review` | ✓ | 命名规范中的唯一标识 |
| 类型 | `Mail-enabled Security Group` | ✓ | 四类标准类型之一 |
| 创建日期 | `2024-03-15` | ✓ | 精确到日 |
| 所有者 | `hr-director@company.com` | ✓ | 单一责任人，非部门邮箱 |
| 成员数 | `12` | ✓ | 当前有效成员数量（含嵌套组展开后） |
| 最后活跃时间 | `2024-06-28T14:22:05Z` | ✓ | 最近一次成功收/发邮件时间（PowerShell 获取） |
| 有效期 | `2025-12-31` | △ | 临时组必填；长期组填 `Permanent` |
| 关联流程 | `HR-Compensation-Review-2024-Q3` | △ | 对应业务流程编号或文档链接 |
| 注销状态 | `Active` / `Archived` / `Pending Deletion` | ✓ | 生命周期状态 |

> 📅 **生命周期规则**：
> - 连续 **180 天无邮件活动** 且无明确有效期的组，自动标记为 `Pending Deletion`，通知所有者确认保留；
> - 标记后 **30 天未响应**，由 IT 运维执行归档（禁用邮箱+保留 AD 对象 90 天）或删除；
> - 归档组可通过 `Get-UnifiedGroup -Filter {ArchiveStatus -eq 'SoftDeleted'}` 查询。

## 附录 A：常用 PowerShell 命令（Exchange Online）

```powershell
# 查看所有邮件组（含类型、成员数、最后活动）
Get-UnifiedGroup | Select DisplayName,GroupType,Members,WhenChanged,LastDeliveredTimestamp | Sort LastDeliveredTimestamp -Descending

# 导出动态组过滤器详情
Get-DynamicDistributionGroup "dg-engineering-all" | FL DisplayName,RecipientFilter,ManagedBy

# 批量清理离职人员（假设离职者UPN含 '-left-'）
$leavers = Get-AzureADUser -Filter "UserPrincipalName eq 'xxx-left@company.com'" 
foreach ($u in $leavers) { Remove-UnifiedGroupLinks -Identity "sg-it-ops" -LinkType Members -Links $u.UserPrincipalName }

# 启用邮件审核（全局生效）
Set-UnifiedGroup -Identity "m365-proj-ai-reviewers" -AuditEnabled $true -AuditLogAgeLimit 180
```
