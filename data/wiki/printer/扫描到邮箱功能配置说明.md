# 扫描到邮箱功能配置说明

## 概述  
“扫描到邮箱”（Scan-to-Email）是公司主流多功能一体机（MFP）支持的核心数字化办公功能，允许用户通过设备控制面板直接将纸质文档扫描并以电子邮件形式发送至指定收件人。本说明适用于公司统一采购的 **Canon imageRUNNER ADVANCE C5560i、Ricoh MP C4504ex、Xerox VersaLink C405** 等主流机型，涵盖网络配置、SMTP 服务设置、权限控制及常见问题排查。

---

## 配置前提条件

### 硬件与网络要求
| 项目 | 要求 |
|------|------|
| 设备固件版本 | Canon：v4.10+；Ricoh：v2.35+；Xerox：v1.22.10+（需通过设备管理界面或 Web UI 查看并升级） |
| 网络连接 | 设备必须接入公司内网 VLAN（通常为 `10.20.x.0/24`），且具备 DNS 解析能力（推荐使用 `10.20.1.10` 和 `10.20.1.11`） |
| SMTP 服务可用性 | 公司统一使用 Microsoft 365 Exchange Online 作为邮件中继，**禁止直连公网 SMTP（如 Gmail、163）**；需确保设备 IP 已加入 M365 合法中继白名单（由 IT 邮件组统一维护） |

### 权限与账号准备
- 设备管理员账号（默认 `admin` / `admin`，首次登录后强制修改）
- 公司邮箱中继认证账号（格式：`scan-relay@company.com`，密码由 IT 安全组提供，有效期90天）
- 扫描发起人无需个人邮箱授权，但收件人地址须为公司域邮箱（`@company.com`）

## 配置步骤（以 Canon imageRUNNER ADVANCE C5560i 为例）

### 步骤 1：启用网络扫描服务  
1. 登录设备 Web UI（浏览器访问 `https://[设备IP]/` → 输入管理员账号）  
2. 进入 **Settings > System Settings > Network Settings > Scan Settings**  
3. 勾选 **Enable Network Scan** 和 **Enable Email Scan**  
4. 点击 **Apply**

### 步骤 2：配置 SMTP 服务器参数  
| 参数 | 值 | 说明 |
|------|----|------|
| SMTP Server Address | `smtp.office365.com` | 必须使用 TLS 加密端口 |
| Port Number | `587` | 不支持 465（SSL）或 25（未加密） |
| Authentication Method | `Login (Username/Password)` | 选择此项，不可选 "None" 或 "POP before SMTP" |
| Username | `scan-relay@company.com` | 统一中继账号，非个人邮箱 |
| Password | ⚠️ 由 IT 门户获取（路径：IT Service Portal → “打印设备密钥申请”） | 密码含大小写字母+数字+特殊字符，长度≥12位 |

> ✅ **验证提示**：配置完成后点击 **Test SMTP Connection**，成功返回 `SMTP connection successful. Authentication OK.` 即为有效。

### 步骤 3：设置默认扫描参数（可选但推荐）  
- 文件格式：`PDF (Searchable)`（启用 OCR，便于后续检索）  
- 分辨率：`300 dpi`（平衡清晰度与附件大小）  
- 文件大小限制：`10 MB`（避免触发 M365 单邮件附件上限）  
- 默认发件人地址：`scan@company.com`（需在 M365 Exchange 后台配置为合法代发地址）

### 步骤 4：发布至设备控制面板  
1. 进入 **Settings > User Management > Quick Copy/Scan Settings**  
2. 新建快捷扫描模板，命名为 **“扫描至邮箱（标准）”**  
3. 关联已配置的 Email 目标，并设置默认收件人字段为「手动输入」  
4. 保存并同步至所有用户组（建议启用 `All Users` 权限）

## 常见错误与处理

| 错误代码 / 现象 | 可能原因 | 解决方案 |
|------------------|-----------|------------|
| `SMTP Auth Failed (535)` | 中继账号密码过期或输入错误 | 重置密码并更新设备配置；检查是否粘贴了隐藏空格 |
| `Connection Timeout (10060)` | 设备无法解析 `smtp.office365.com` 或防火墙拦截 587 端口 | 在设备命令行执行 `ping smtp.office365.com` 和 `telnet smtp.office365.com 587` 验证连通性；联系网络组开通对应 ACL |
| `Attachment size exceeds limit` | 单页扫描超 10MB（多图/高DPI/未压缩 TIFF） | 改用 PDF 格式 + “Auto Compress” 选项；禁用 TIFF 输出 |
| 扫描邮件收件人未收到，但设备显示“发送成功” | M365 邮件流规则拦截（如含敏感关键词、外部转发限制） | 查看 M365 后台 **Mail Flow > Message Trace**，筛选 `Subject: SCAN_` 追踪状态；联系邮件管理员放行 `scan@company.com` 发信策略 |

## 合规与安全提醒  
- ❗ 所有扫描到邮箱操作均记录于设备日志（保留90天），包含操作者账号/IP、时间、目标邮箱、文件页数，审计时可导出 CSV。  
- ❗ 禁止扫描含 PII（个人身份信息）、PCI（银行卡号）、HIPAA（健康数据）等敏感内容的文档；如确需处理，须提前提交《扫描敏感数据审批单》至 DPO 办公室。  
- ✅ 推荐替代方案：对高敏文档，优先使用「扫描至 SharePoint」或「扫描至加密 USB」方式。
