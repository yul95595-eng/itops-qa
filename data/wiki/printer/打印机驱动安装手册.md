# 打印机驱动安装手册

> 本手册适用于公司内部所有 Windows 和 macOS 操作系统下的主流品牌打印机（HP、Canon、Epson、Brother、Kyocera）驱动安装与基础故障排查，版本：v2.3（2024-Q3 更新）

---

## 一、安装前准备

### 1.1 确认打印机型号与连接方式  
- **型号识别**：查看打印机正面/背面标签，例如 `HP LaserJet Pro MFP M428fdw` 或 `Canon imageCLASS MF644Cdw`。  
- **连接类型**（三选一）：
  - ✅ USB 直连（推荐首次安装）
  - ✅ 有线网络（需确认打印机已获取 IP 地址，如 `192.168.1.128`）
  - ⚠️ 无线直连（Wi-Fi Direct）或云打印（仅限支持机型，需额外配置）

### 1.2 系统兼容性检查  

| 操作系统 | 支持驱动类型 | 官方驱动下载路径示例 |
|----------|----------------|--------------------------|
| Windows 10/11（64位） | WHQL 认证 INF 驱动 / HP Smart / Canon IJ Setup | [support.hp.com](https://support.hp.com) / [canon-asia.com/support](https://www.canon-asia.com/support) |
| macOS 12 Monterey 及以上 | IPP Everywhere（免驱） / 厂商专用PKG | 系统「系统设置 > 打印机与扫描仪」自动识别，或厂商官网下载 `.pkg` |
| Windows Server 2016+ | PCL6 / PostScript（需管理员权限部署） | 仅限IT部门通过组策略分发 |

> 💡 提示：Windows 11 默认启用「打印机驱动程序强制签名」，禁用非签名驱动需临时启用测试模式（不推荐生产环境使用）。

## 二、标准安装流程（以 Windows 10/11 为例）

### 2.1 USB 连接安装（推荐新手）

1. 关闭打印机电源，用原装 USB 线连接电脑与打印机；
2. 开启打印机，等待就绪指示灯常亮；
3. **Windows 自动检测**（约15–30秒）：
   - 若弹出「找到新硬件」→ 点击「安装驱动程序」→ 选择「自动从 Windows Update 获取」；
   - 若未弹出 → 手动触发：  
     `设置 > 蓝牙和其他设备 > 打印机和扫描仪 > 添加打印机或扫描仪 > 我的打印机未列出 > 使用 USB 连接的打印机`；
4. 安装完成后，系统将自动创建默认队列（如 `HP_M428fdw_USB_1`），并提示「设置为默认打印机」；
5. **验证打印**：右键打印机图标 → 「管理」→ 「打印测试页」。

### 2.2 网络打印机手动添加（IP 方式）

1. 获取打印机 IP 地址（通过打印机控制面板：`设置 > 网络设置 > IPv4 地址`）；
2. 打开 `控制面板 > 设备和打印机 > 添加打印机`；
3. 选择 **「我需要的打印机不在列表中」** → 「按 TCP/IP 地址或主机名添加打印机」；
4. 输入 IP（如 `192.168.1.128`），端口名自动生成（如 `IP_192.168.1.128`），协议保持「TCP/IP」；
5. 点击「下一步」→ 选择厂商与型号 → 若列表无匹配项，点击「从磁盘安装」→ 浏览至已下载的 `.inf` 文件（如 `hpzins01.inf`）；
6. 完成安装后，**务必勾选「设为默认打印机」并运行测试页**。

## 三、常见问题与错误码速查

| 错误现象 | 可能原因 | 解决方案 |
|----------|-----------|------------|
| ❌ “驱动程序未签名”（Windows） | 第三方/旧版驱动未通过微软认证 | 下载官网最新 WHQL 驱动；或临时禁用驱动签名（仅调试）：<br>`bcdedit /set testsigning on` → 重启 |
| ❌ “无法连接到打印机”（网络） | 打印机离线 / 防火墙拦截 / IP 冲突 | ① Ping 打印机 IP；② 检查路由器 DHCP 分配是否稳定；③ 临时关闭 Windows Defender 防火墙测试 |
| ❌ 打印任务卡在“正在删除”或“正在处理” | 打印后台处理服务异常 | 以管理员身份运行 CMD：<br>`net stop spooler` → 删除 `C:\Windows\System32\spool\PRINTERS\*.*` → `net start spooler` |
| 🖨️ macOS 显示“无法验证开发者” | Gatekeeper 阻止未公证PKG | 右键安装包 → 「打开」→ 点击「仍要打开」；或执行：<br>`sudo xattr -rd com.apple.quarantine /path/to/CanonInstaller.pkg` |
