# 打印乱码与字体缺失排查指南

> 本文档适用于公司内部 IT 运维人员及终端用户，用于快速定位和解决 Windows/macOS 环境下常见打印输出异常问题（如：中文显示为方框、符号、问号、乱码字符，或部分字体完全不可用）。

---

## 一、常见现象归类

| 现象类型         | 典型表现                                                                 | 可能根因                     |
|------------------|--------------------------------------------------------------------------|------------------------------|
| **全文档乱码**   | 所有文字变为 `□□□`、``、`?` 或 ASCII 符号（如 `A`, `B`, `1` 替代汉字）     | 驱动不兼容 / PCL/PS 模式误配 |
| **局部字体缺失** | 仅特定字体（如「思源黑体」「微软雅黑」「苹方-简」）无法正确渲染，其余正常 | 字体未嵌入 / 打印机不支持该字体 |
| **PDF 打印异常** | 浏览器/Adobe Reader 中预览正常，但打印后出现乱码或空白区域                 | PDF 渲染引擎与打印机固件不匹配 |
| **Word/Excel 乱码** | Office 文档中正常显示，打印后标题/页眉/批注等位置出现方块或错位字符          | Office 字体替换策略触发 / GDI 渲染异常 |

---

## 二、基础排查步骤（按优先级执行）

### ✅ 步骤 1：确认打印机驱动版本与兼容性  
- **Windows**：  
  - 进入「设置 > 蓝牙和其他设备 > 打印机和扫描仪」→ 右键目标打印机 → 「管理」→ 「打印机属性」→ 「高级」选项卡 → 查看驱动程序提供者与日期；  
  - **推荐操作**：卸载当前驱动，从打印机厂商官网下载**最新 WHQL 认证驱动**（避免使用 Windows Update 自动安装的通用驱动）。  

- **macOS**：  
  - 进入「系统设置 > 打印机与扫描仪」→ 选中打印机 → 点击「…」→ 「打开打印机软件」→ 查看版本号；  
  - 若为 IPP 或 AirPrint 模式，建议改用厂商提供的 **CUPS PPD 驱动包**（尤其对 HP/Lexmark/Canon 中文支持更优）。

### ✅ 步骤 2：检查打印语言（PCL vs PostScript）匹配  
- 在打印机属性中定位「端口」或「设备设置」选项卡，确认：  
  - 若文档含大量中文字体/复杂排版 → **优先启用 PostScript（PS）模式**（需 PS 许可或内置 PS 解析器）；  
  - 若为老旧激光打印机（如 HP LaserJet M506）→ 使用 **PCL6（增强模式）**，并关闭「TrueType 字体下载」选项（防止字体冲突）；  
  - ⚠️ 错误配置示例：在仅支持 PCL 的设备上强制发送 PS 数据流 → 导致整页乱码或卡纸。

### ✅ 步骤 3：验证字体嵌入与下载策略  
- **Windows GDI 打印路径**（默认）：  
  - 打开「打印机属性 > 高级 > 打印处理器」→ 确认为 `WinPrint`；  
  - 「高级 > 新建文档默认设置」→ 勾选 **“将 TrueType 字体下载为软字体”**（适用于大多数中文字体）；  
  - 若仍异常，尝试切换为 **“始终下载 TrueType 字体”**（增加数据量但兼容性更高）。

- **macOS CUPS 路径**：  
  - 编辑 `/etc/cups/printers.conf`，确认对应打印机段落含：  
    ```conf
    Option pdf-fitplot true
    Option pdftops-prepress true  # 启用高质量 PDF 渲染
    ```

### ✅ 步骤 4：测试标准字体与嵌入能力  
- 创建测试文档（Word/TextEdit），输入以下内容并打印：  
  ```
  正常字体：宋体、黑体、Arial、Helvetica  
  特殊字体：思源黑体 CN Heavy、Noto Sans SC Bold、PingFang SC  
  Unicode 测试：① ② ③｜α β γ｜✓ ✗ ★  
  ```
- 若仅「思源黑体」「Noto Sans SC」等开源字体乱码 → 表明打印机**固件不支持 OpenType/CFF 字体子集**，需：  
  - 更换为 Windows 自带的 `SimHei.ttf` / `MSYH.TTF`；  
  - 或在 Word 中启用「文件 > 选项 > 保存 > 勾选『将字体嵌入文件』」（仅限 .docx）。

## 三、进阶诊断工具与日志

| 工具名称         | 用途说明                                                                 | 启动方式（Windows）                              |
|------------------|--------------------------------------------------------------------------|--------------------------------------------------|
| **Print Spooler 日志** | 查看 spooler 是否丢弃字体数据包                                          | `eventvwr.msc` → Windows 日志 → 应用程序 → 筛选“Print”事件 |
| **HP UPD Diagnostics** | HP 通用打印驱动自带诊断（检测字体缓存、PS 解析错误）                      | 安装 HP UPD 后右键打印机 → 「诊断工具」             |
| **CUPS Web 管理界面** | macOS/Linux 下查看实时打印队列、错误消息（如 `font not found`、`invalid font type`） | 浏览器访问 `http://localhost:631`                |

> 🔍 **典型错误码参考**：  
> - `ERROR_FONT_NOT_FOUND (0x00000709)`：系统找不到指定字体（检查字体是否被禁用/损坏）；  
> - `ERROR_INVALID_PRINTER_DRIVER (0x0000070B)`：驱动签名异常或架构不匹配（x64 驱动用于 x86 系统）；  
> - CUPS 日志中 `E [date] Missing font 'NotoSansCJKsc-Bold'`：需手动将 `.ttf` 文件复制至 `/usr/share/cups/fonts/` 并重启服务。

## 四、临时规避方案（应急使用）

- ✅ **PDF 转图像打印**：用 Adobe Acrobat →「文件 > 导出为 > 图像 > PNG/JPEG」→ 再打印（牺牲缩放精度，但 100% 避免字体问题）；  
- ✅ **Office「另存为 XPS」→ 打印 XPS 文件**：XPS 格式固化字体与布局，绕过 GDI 渲染链；  
- ✅ **更换打印协议**：禁用 IPP，改用 **TCP/IP 端口（端口 9100）+ RAW 协议**（适用于企业级喷墨/高速复合机）。

---

> 📌 **附：字体合规性检查清单**  
> - [ ] 所有中文字体已安装于 `C:\Windows\Fonts`（Windows）或 `/Library/Fonts`（macOS）；  
> - [ ] 字体文件未被第三方安全软件隔离（检查 Defender/火绒隔离区）；  
> - [ ] 打印机固件已升级至最新版（尤其 Canon iR-ADV、Ricoh MP 系列需固件支持 GB18030）；  
> - [ ] 多用户环境中，确认字体安装为「为所有用户安装」而非仅当前账户。
