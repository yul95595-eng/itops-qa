# 共享打印机连接与权限设置

## 概述  
本指南适用于公司内部 Windows 环境下，通过局域网共享打印机并为不同用户/用户组配置访问与打印权限的操作流程。适用于 IT 运维人员及部门管理员，确保打印机资源安全、可控、高效复用。

---

## 前置条件

- 打印机已物理连接至**主机（共享端）** 并能本地正常打印  
- 主机操作系统为 Windows 10/11 或 Windows Server 2016+  
- 客户端与主机处于同一局域网（建议使用固定 IP 或 DNS 可解析主机名）  
- 已启用网络发现、文件和打印机共享（见下文配置步骤）  
- 用户账户具备本地管理员权限（共享端）或“管理打印机”权限（可选高级配置）

---

## 一、在共享端配置打印机共享

### 1. 启用网络发现与共享服务
1. 打开「控制面板」→「网络和 Internet」→「网络和共享中心」  
2. 点击左侧「更改高级共享设置」  
3. 在当前网络配置文件（如「专用」）下启用：  
   - ✔️ 启用网络发现  
   - ✔️ 启用文件和打印机共享  
   - ❌ 关闭密码保护共享（*若需匿名访问*；否则保持启用，要求凭据验证）

### 2. 共享打印机
1. 打开「设置」→「蓝牙和其他设备」→「打印机和扫描仪」  
2. 选择目标打印机 → 点击「管理」→「打印机属性」  
3. 切换到「共享」选项卡：  
   - ✔️ 勾选「共享这台打印机」  
   - 输入共享名称（建议命名规范：`PRN-Dept-Model`，如 `PRN-FIN-HPM428dw`）  
   - （可选）勾选「允许其他用户管理此打印机」以授予普通用户暂停/取消作业权限  

> ⚠️ 注意：若点击「应用」后提示“无法保存打印机设置”，常见原因包括：  
> - Print Spooler 服务未运行 → 运行 `services.msc` → 启动 **Print Spooler** 服务  
> - 组策略禁用打印机共享 → 检查 `gpedit.msc` → 计算机配置 → 管理模板 → 打印机 →「允许打印机共享」设为「已启用」

## 二、客户端连接共享打印机

### 方法 A：通过网络路径手动添加（推荐，兼容性高）
1. 按 `Win + R`，输入：  
   ```
   \\[主机IP地址或主机名]\[共享名称]
   ```  
   示例：`\\192.168.1.100\PRN-FIN-HPM428dw` 或 `\\PRINT-SVR\PRN-HR-Lexmark`

2. 若提示凭据，输入**共享端有效的用户名与密码**（格式：`主机名\用户名` 或 `域名\用户名`）  
3. 系统自动下载并安装驱动（需共享端已部署兼容驱动）；若失败，勾选「始终使用此驱动程序」并指定 `.inf` 文件路径。

### 方法 B：通过「添加打印机」向导自动发现
1. 「设置」→「蓝牙和其他设备」→「打印机和扫描仪」→「添加打印机或扫描仪」  
2. 点击「我需要的打印机不在列表中」→「按名称选择共享打印机」  
3. 输入 `\\[主机名]\[共享名]`，完成安装  

> ✅ 成功标志：打印机图标显示「已连接」，且可右键「管理」查看队列状态。

## 三、权限精细化管理（高级）

Windows 共享打印机支持基于用户/组的细粒度权限控制，通过「打印机属性 → 安全」选项卡配置：

| 权限项 | 说明 | 推荐授予对象 |
|--------|------|----------------|
| **管理打印机** | 暂停/恢复/清空队列、更改设置、接管作业 | IT管理员组、部门打印机管理员 |
| **管理文档** | 暂停/恢复/删除**自己或其他人**的打印任务 | 部门主管、文印专员 |
| **打印** | 提交新打印任务（默认所有认证用户拥有） | “Everyone”（启用密码保护时）或指定部门组 |

### 设置示例（以 `PRN-FIN-HPM428dw` 为例）：
1. 右键打印机 → 「打印机属性」→ 「安全」选项卡  
2. 点击「添加」→ 输入组名（如 `FIN-Users`）→ 「检查名称」→ 确定  
3. 为 `FIN-Users` 勾选：✅ 打印  
4. 为 `FIN-Managers` 勾选：✅ 打印 + ✅ 管理文档  
5. 为 `Domain Admins` 勾选：✅ 打印 + ✅ 管理文档 + ✅ 管理打印机  

> 🔒 权限继承说明：若勾选「替换所有子对象的权限项」，将覆盖驱动级权限，谨慎操作。

## 四、常见问题排查

| 现象 | 可能原因 | 解决方案 |
|------|----------|-----------|
| 客户端找不到共享打印机 | 主机防火墙阻止 SMB（TCP 445） | 关闭防火墙临时测试；或添加入站规则放行 `File and Printer Sharing (SMB-In)` |
| 连接后提示“操作无法完成（错误 0x00000709）” | 注册表 `RestrictRemoteClients` 被禁用共享 | 运行 `regedit` → 定位 `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Print` → 将 `RestrictRemoteClients` 值设为 `0` → 重启 Print Spooler |
| 打印任务卡在“正在连接” | 主机脱网 / NetBIOS 名称解析失败 | 使用 IP 地址连接替代主机名；或在客户端 `C:\Windows\System32\drivers\etc\hosts` 添加映射：`192.168.1.100 PRINT-SVR` |
| 用户能连接但无法打印（权限拒绝） | “打印”权限未授予该用户/组 | 检查打印机「安全」选项卡，确认用户所属组具有「打印」权限 |

|------|-----------|
