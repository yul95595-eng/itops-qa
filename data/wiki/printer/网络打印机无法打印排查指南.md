# 网络打印机无法打印排查指南

> 本文档适用于公司内部网络环境下的 IP 打印机（支持 TCP/IP 协议，非 USB 直连或蓝牙设备），涵盖常见故障现象、系统化排查流程及典型错误码处理建议。

---

## 一、基础状态确认（5 分钟内完成）

请按顺序快速验证以下 4 项基础连通性与配置：

1. **打印机物理状态**  
   - 电源指示灯常亮（非闪烁/熄灭）  
   - 控制面板无报错提示（如 “Paper Jam”, “Toner Low”, “Cover Open”）  
   - 网络接口灯（LAN 口）绿色常亮或规律闪烁（表明物理链路正常）

2. **IP 地址有效性**  
   - 在打印机控制面板中进入「网络设置」→「TCP/IP 设置」，确认已获取有效 IPv4 地址（非 `0.0.0.0` 或 `169.254.x.x`）  
   - 若为 DHCP 获取，检查公司 DHCP 服务是否正常；若为静态 IP，请核对子网掩码、网关与 DNS 是否与办公网段一致（例：`10.20.30.128/24`, 网关 `10.20.30.1`）

3. **PC 端网络可达性**  
   - 在客户端 Windows/macOS 终端执行：  
     ```bash
     ping -c 4 <打印机IP>   # macOS/Linux
     ping -n 4 <打印机IP>   # Windows
     ```
     ✅ 预期结果：`4 个包全部返回，丢包率 0%`  
     ❌ 若超时或部分丢失 → 进入【二、网络层排查】

4. **打印队列状态清空**  
   - Windows：`控制面板 > 设备和打印机 > 右键目标打印机 > 查看打印队列 > 取消所有文档`  
   - macOS：`系统设置 > 打印机与扫描仪 > 选择打印机 > 点击「打开打印队列」> 清除所有作业`

## 二、网络层深度排查

| 检查项 | 操作方法 | 正常表现 | 异常处理建议 |
|--------|----------|-----------|----------------|
| **端口连通性（IPP/Socket）** | `telnet <打印机IP> 631`（IPP）<br>`telnet <打印机IP> 9100`（Raw Socket） | 显示空白屏幕或 `Connected...` | 若连接拒绝（Connection refused）：检查打印机是否启用 IPP 服务（部分型号需在 Web 管理界面开启）；9100 端口关闭可能因固件限制或防火墙拦截 |
| **ARP 表解析** | `arp -a \| findstr "<打印机IP>"`（Win）<br>`arp -a \| grep "<打印机IP>"`（macOS/Linux） | 返回对应 MAC 地址（如 `00-1e-37-xx-xx-xx`） | 若无条目 → 执行 `arp -d *` 清空缓存后重试 ping；仍失败则检查交换机端口 VLAN 配置是否隔离 |
| **中间设备策略** | 登录核心交换机/防火墙，检查：<br>- 打印机所在 VLAN 是否允许 `TCP 631/9100` 出向流量<br>- 是否启用「ARP Inspection」或「DHCP Snooping」导致异常拦截 | 策略日志无 deny 记录 | 联系网络管理员临时放行测试，确认后固化策略 |

> ⚠️ 注意：公司统一部署的终端安全软件（如 CrowdStrike、Symantec Endpoint）可能默认拦截 9100 端口通信，请在客户端临时禁用防护模块验证。

## 三、驱动与服务层诊断

### 3.1 Windows 系统关键服务检查（以管理员身份运行 PowerShell）

```powershell
# 必须运行的服务（状态应为 Running）
Get-Service Spooler, FDResPub, Dnscache | Select-Object Name, Status, StartType

# 若 Spooler 停止，重启并设为自动启动：
Restart-Service Spooler -Force
Set-Service Spooler -StartupType Automatic
```

### 3.2 驱动兼容性验证表

| 打印机品牌 | 推荐驱动类型 | 兼容性风险提示 |
|------------|----------------|------------------|
| HP LaserJet / Color LaserJet | **HP Universal Print Driver (UPD) PCL6 / PostScript** | 避免使用“Basic Driver”或 Windows 自带 Generic / Text Only 驱动 |
| Canon imageCLASS / iR Series | **Canon UFR II LT / UFR II v3.5+** | Windows 11 22H2+ 需更新至 v3.7 以上，否则出现「0x00000709」错误 |
| Brother HL-Lxxx / MFC-Lxxx | **Brother CUPS Driver（macOS）<br>Brother Printer Driver（Windows）** | 切勿混用 BR-Script 与 PCL 驱动版本，易致字体乱码或卡死 |

> 🔍 验证方式：打印「配置页」或「网络设置页」（通常通过打印机面板组合键触发，如 `Menu > Information > Print Report`）。若可成功打印该页，说明硬件与基础网络正常，问题大概率出在客户端驱动或策略。

## 四、典型错误码速查表

| 错误码（Windows 事件查看器 / 打印队列状态） | 含义 | 解决步骤 |
|---------------------------------------------|------|-----------|
| `0x00000709` | 无法连接到打印机（RPC 服务异常或驱动签名不匹配） | ① 更新驱动至官网最新版；② 执行 `sfc /scannow`；③ 组策略中禁用「设备驱动程序强制签名」（仅测试环境） |
| `0x00000002` | 系统找不到指定文件（常因端口配置错误） | 检查打印机端口是否为标准 TCP/IP 端口（非 LPT1 或 WSD）；删除旧端口后重新添加，勾选「查询打印机以获取端口信息」 |
| `0x000003eb` | 打印后台处理程序无法启动（Spooler 依赖服务故障） | 重启 `Dnscache`、`FDResPub` 服务；检查磁盘空间（`C:\Windows\System32\spool\PRINTERS` 目录需 ≥500MB 空闲） |
| `0x000007d1` | 打印机脱机（但实际在线） | 右键打印机 →「查看正在打印什么」→ 菜单栏「打印机」→ 取消勾选「脱机使用打印机」 |

## 五、附录：快速复位操作（慎用）

当上述步骤均无效时，可尝试以下**最后手段**（将清除网络配置与作业缓存）：

1. 关机打印机，拔掉网线与电源线  
2. 长按「取消/停止」键（或「Go」键，依型号而异）不放，插回电源  
3. 待面板显示 `Resetting...` 或连续蜂鸣后松手  
4. 等待重启完成，重新配置 IP 并添加至客户端  

> 📌 提示：重置前请记录当前 IP、纸张尺寸等关键配置；部分企业级机型（如 HP Enterprise、Xerox AltaLink）需通过 Web 界面执行「Factory Reset」而非物理按键。
