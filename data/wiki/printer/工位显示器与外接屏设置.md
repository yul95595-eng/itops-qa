## 一、常见配置场景说明

| 场景 | 适用设备类型 | 连接方式 | 支持分辨率（最高） | 备注 |
|------|----------------|------------|------------------------|------|
| 笔记本单外接显示器 | ThinkPad / MacBook / Dell XPS 等主流商务本 | HDMI / USB-C / Mini DisplayPort | 4K@60Hz（需接口及显卡支持） | MacBook 需确认 macOS 版本 ≥12.3 |
| 台式机双屏扩展 | 公司标配台式机（Intel Core i5/i7 + 集显/独显） | HDMI + DP 或双 HDMI | 主屏 2560×1440，副屏 1920×1080 | 集显建议使用 DP 接口以保障多屏稳定性 |

## 二、Windows 系统外接屏设置步骤（以 Win11 为例）

### ### 1. 物理连接与基础识别

1. 确保显示器已通电，信号线（HDMI/DP/USB-C）两端牢固插入；
2. 笔记本/台式机开机后等待 10–15 秒，系统自动识别新显示器；
3. 若无响应，按快捷键 `Win + P` 打开投影菜单，依次尝试：
   - 「仅电脑屏幕」→「复制」→「扩展」→「仅第二屏幕」；
4. 若仍无法识别，请检查：
   - 显示器输入源是否匹配（如 HDMI1 / DP2）；
   - 显卡驱动是否为最新版（推荐通过 [Intel](https://www.intel.cn/content/www/cn/zh/support/detect.html) / [NVIDIA 控制面板 → 帮助 → 系统信息 → 驱动版本] 查验）；
   - BIOS 中是否禁用了核显（部分机型需开启「iGPU Multi-Monitor」选项）。

### ### 2. 系统级显示设置（扩展模式推荐）

1. 右键桌面空白处 → 选择「显示设置」；
2. 在「多个显示器」区域，确认所有屏幕已显示为灰色方框（编号 1、2、3…）；
3. 拖拽方框调整物理布局，使其与实际摆放顺序一致（关键！影响鼠标移动逻辑）；
4. 分别点击各显示器缩略图，设置：
   - **分辨率**：优先选择「推荐」，避免模糊或缩放异常；
   - **缩放与布局**：统一设为 100% 或 125%（不建议混用，易致窗口错位）；
   - **方向**：默认「横向」，竖屏用户请选「纵向」并勾选「使文本和应用更清晰」；
5. 下拉至「相关设置」→「图形设置」→「浏览」添加常用软件（如 Chrome、IDEA），为其单独指定「高性能 GPU」（如有独显）。

## 三、macOS 系统外接屏设置要点

- **镜像模式限制**：macOS 13+ 默认禁止不同分辨率显示器镜像显示，若强制开启可能触发「画面撕裂」或「黑边」；
- **HiDPI 缩放**：在「系统设置 → 显示器」中，按住 `Option` 键点击「缩放」可解锁更多 HiDPI 分辨率选项；
- **USB-C 转接器兼容性警告**：
  - ❌ 不推荐使用非 MFi 认证的 USB-C to HDMI 多合一扩展坞（易导致睡眠唤醒失败、USB 设备断连）；
  - ✅ 推荐型号：Satechi ST-TCMMS（支持 PD 100W + DP Alt Mode）、Caldigit TS4（雷电4全功能）；
- **常见错误码参考**：
  | 错误现象 | 可能原因 | 解决方案 |
  |----------|-----------|------------|
  | 屏幕闪烁/白屏 | macOS 14.5+ 与某些 DP 1.2 线缆兼容性问题 | 更换为 DP 1.4 线缆或改用 USB-C 直连 |
  | 外接屏无声音输出 | 系统未将显示器音频设为默认输出设备 | 「系统设置 → 声音 → 输出」中手动选择显示器名称（如 “Dell U2723QE”） |
  | 鼠标移出边界丢失 | 多显示器排列逻辑错误 | 重进「显示器」设置，拖动屏幕缩略图确保左右/上下连续无缺口 |

## 四、故障速查表（高频问题）

| 现象 | 初步排查项 | 进阶处理 |
|------|--------------|-------------|
| 外接屏黑屏，主机识别为“未知显示器” | ✅ 检查线缆是否支持所需带宽（如 4K@60Hz 需 HDMI 2.0 / DP 1.2+）<br>✅ 尝试更换接口（如从 HDMI 换到 DP） | ▶ 更新显卡固件（如 Intel Graphics Command Center →「系统」→「固件更新」）<br>▶ 在 BIOS 中重置显示设置（Load Default Settings） |
| 扩展模式下鼠标无法跨屏 | ✅ 核对显示器排列顺序是否与物理位置一致<br>✅ 关闭「平板模式」及「自动旋转」 | ▶ 运行 `dxdiag` →「显示」页签查看多显卡协同状态<br>▶ 删除 `C:\Users\[用户名]\AppData\Roaming\Microsoft\Display\` 下缓存文件后重启 |
| 文字模糊、图标发虚 | ✅ 确认缩放比例统一且启用「允许 Windows 尝试修复应用缩放问题」 | ▶ 右键程序快捷方式 →「属性」→「兼容性」→ 勾选「替代高 DPI 缩放行为」→ 选「应用程序」 |
