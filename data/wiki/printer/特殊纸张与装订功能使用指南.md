# 特殊纸张与装订功能使用指南

> **适用设备**：公司标准配置的 A3 幅面多功能数码复合机（型号：Ricoh MP C4504ex / Canon imageRUNNER ADVANCE C5560i / Konica Minolta bizhub C458，固件版本 ≥ V3.20）  
> **适用场景**：厚纸打印、信封输出、标签纸、再生纸、小册子制作、骑马钉/ staples 装订等专业输出需求  

---

## 一、特殊纸张支持规范

### 1.1 支持纸张类型与规格限制

| 纸张类型 | 克重范围（g/m²） | 尺寸范围（mm） | 注意事项 |
|----------|------------------|----------------|----------|
| 厚纸（卡纸） | 120–300 g/m² | A6–A3（105×148 mm 至 297×420 mm） | ≥256 g/m² 需启用「厚纸模式」；进纸前需扇动纸张并校准堆叠高度 |
| 信封 | 70–120 g/m² | DL、C5、COM10、Monarch（需在驱动中预设尺寸） | 仅支持后置手送托盘（Bypass Tray）；禁用自动双面 |
| 标签纸（带底纸） | 160–220 g/m²（含底纸） | A4（210×297 mm）单页 | 必须选择「标签纸」介质类型；禁用定影温度自动调节 |
| 再生纸（环保纸） | 60–100 g/m² | A4/A5/B5 | 建议启用「再生纸模式」以降低搓纸风险；避免使用卷曲或受潮纸张 |
| 透明胶片（OHP） | 100–160 μm（厚度） | A4/A5（仅限指定品牌兼容胶片） | 仅支持手送托盘；打印后需静置冷却 ≥30 秒再触碰 |

> ⚠️ **禁止使用**：金属箔纸、自粘背胶非标标签、PVC 材质卡片、含蜡涂层纸、折叠式信封（未展开）、湿度＞65% RH 的纸张。

## 二、装订功能操作流程（以骑马钉/小册子装订为例）

### 2.1 前置条件确认

1. 打印机已安装**装订单元（Finisher-S2 或 D-SD1）**，且状态灯常绿无告警；
2. 驱动程序为最新版（Ricoh/Canon/KM 官网下载对应型号「PS/PCL/UFR II」驱动）；
3. 文档为 PDF 或可编辑格式（Word/Excel 需另存为 PDF 并勾选「保留书签与页面缩略图」）；
4. 页面总数为 **4 的整数倍**（骑马钉最小装订单元为 4 页）；若不足，系统将自动插入空白页补足。

### 2.2 操作步骤（Windows 端驱动设置）

1. 打开文档 → `Ctrl+P` 调出打印对话框；
2. 选择对应打印机 → 点击 **「属性」或「首选项」**；
3. 切换至 **「完成选项」或「装订/整理」选项卡**；
4. 启用 **「小册子打印（Booklet）」**，设置：
   - 小册子类型：`A4 折叠为 A5`（默认）或 `A3 折叠为 A4`（需手动选择纸盒）；
   - 装订边：`左侧`（纵向）或 `短边`（横向小册子）；
   - 装订方式：`骑马钉（Saddle Stitch）`；
5. 在 **「纸张/质量」选项卡** 中：
   - 「介质类型」选择对应纸张（如：`厚纸 256g`）；
   - 「打印质量」建议设为 `标准` 或 `高质量`（避免“草稿”模式导致装订错位）；
6. 点击 **「确定」→「打印」**，设备将自动执行：  
   ▶ 分页排序 → ▶ 双面打印 → ▶ 输送至装订单元 → ▶ 折页 → ▶ 骑马钉装订 → ▶ 堆叠输出。

> ✅ **验证提示**：装订完成后，设备控制面板显示 `FINISH: BOOKLET DONE`，且输出堆叠整齐、钉距居中（标准钉距：距边缘 12±1 mm）。

## 三、常见问题与错误码处理

| 错误现象 | 可能原因 | 解决方案 |
|----------|-----------|------------|
| **E-000123-0001**（装订失败） | 纸张未对齐/厚度超限/装订单元卡纸 | 打开装订单元盖板 → 清除残留钉脚与碎纸 → 重新校准纸张导板位置 → 关机重启 |
| 输出页序混乱（如第3页出现在第1位） | 未启用「小册子布局」或PDF未嵌入正确逻辑页序 | 使用 Adobe Acrobat「打印为小册子」预处理，或在驱动中勾选 `按逻辑顺序排列（Logical Page Order）` |
| 骑马钉歪斜或单侧脱钉 | 厚纸未启用「厚纸模式」；或装订单元钉匣缺钉 | 进入设备管理界面 → `机器设置 > 装订设置 > 钉匣状态` 查看余量；更换新钉匣（型号：Ricoh STAPLE-CARTRIDGE S2 / Canon F12-01） |
| 信封打印后褶皱/卡在定影部 | 信封含胶层受热软化粘连 | 改用「低温定影模式」（驱动中勾选 `信封专用模式`）；或改用手送托盘 + 关闭节能定影加热 |

## 四、维护建议

- 每月清洁装订单元钉槽与折页辊（使用无绒布+少量异丙醇）；
- 厚纸/标签纸连续作业超过 50 页时，暂停 2 分钟散热；
- 装订类任务建议优先使用「设备端作业存储」功能（通过 Web UI 提交），避免 PC 睡眠中断流程。
