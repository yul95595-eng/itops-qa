# 双面打印与默认设置调整

## 概述  
本指南适用于公司内部常用打印机型号（HP LaserJet Pro MFP M428fdw、Canon imageCLASS MF644Cdw、Xerox VersaLink C405），涵盖双面打印功能启用、默认打印设置持久化配置，以及常见问题排查。所有操作均基于 Windows 10/11 企业版环境（版本 22H2 及以上）及标准域控策略部署场景。

---

## 一、启用双面打印功能

### 1.1 驱动级配置（推荐：确保硬件支持）

| 打印机型号         | 是否原生支持自动双面 | 需安装的驱动组件             | 双面选项路径（Windows 设置中）                     |
|--------------------|----------------------|------------------------------|--------------------------------------------------|
| HP LaserJet M428fdw | 是（标配双面器）     | HP Universal Print Driver (UPD) v7.0+ | `设备和打印机` → 右键属性 → `首选项` → `装订/双面` → 选择“双面打印（长边翻转）” |
| Canon MF644Cdw      | 是（需选配双面器）   | CAPT Driver v6.0 或 UFR II LT v3.5 | `打印首选项` → `完成`选项卡 → 勾选“双面打印”并指定翻转方向 |
| Xerox C405          | 是（标配）           | Xerox Standard Driver v4.5+  | `打印机属性` → `配置` → `双面/小册子` → 启用“双面打印” |

> ⚠️ 注意：若“双面打印”选项为灰色不可选，请检查：
> - 打印机物理双面器是否已正确安装并通电；
> - 驱动程序是否为最新版本（访问厂商官网下载对应型号的 **PCL6** 或 **PostScript** 驱动）；
> - 设备管理器中是否存在“打印队列错误”或“端口未响应”警告（错误码 `0x00000709` 表示端口通信异常）。

### 1.2 应用层默认设置（Word / Excel / Chrome）

#### 在 Microsoft Office 中设为默认双面：
1. 打开任意 Word 文档 → 点击「文件」→「选项」；  
2. 进入「显示」→ 勾选「在打印对话框中显示“双面打印”选项」；  
3. 返回「文件」→「打印」→ 点击「打印机属性」→ 设置双面模式 → 点击「设为默认值」；  
4. **关键步骤**：关闭 Word 并重启，验证下次新建文档是否继承该设置（Office 默认值存储于 `%APPDATA%\Microsoft\Templates\Normal.dotm` 的打印配置区）。

#### 在 Google Chrome 中强制双面（仅限本地打印）：
- 地址栏输入：`chrome://settings/printing`  
- 点击「管理」→ 选择目标打印机 → 「编辑」→ 勾选「双面打印」→ 保存；  
- *注：Chrome 不支持“长边/短边翻转”细粒度控制，系统将按驱动默认逻辑处理。*

## 二、持久化默认打印设置（面向IT管理员）

### 2.1 组策略批量部署（域环境）

通过组策略对象（GPO）统一配置用户级默认打印选项：

1. 打开「组策略管理控制台」（GPMC）；  
2. 创建新 GPO 或编辑现有策略（如 `Printer_Defaults_Policy`）；  
3. 导航至：  
   `用户配置 → 策略 → 管理模板 → 控制面板 → 打印机`；  
4. 启用策略：  
   ✅ **“将默认打印机设置为…”** → 指定公司标准打印机（如 `HP-M428fdw-Corp`）；  
   ✅ **“阻止更改默认打印机”** → 防止用户覆盖；  
5. 进阶配置（需自定义 ADMX）：  
   - 使用 `PrintUIEntry` 命令导出当前用户默认设置为 `.prn` 文件：  
     ```cmd
     rundll32 printui.dll,PrintUIEntry /Ss /n "HP-M428fdw-Corp" /a "C:\Temp\HP_Defaults.prn"
     ```  
   - 通过登录脚本部署该配置：  
     ```cmd
     rundll32 printui.dll,PrintUIEntry /Sr /n "HP-M428fdw-Corp" /a "C:\Temp\HP_Defaults.prn"
     ```

### 2.2 注册表固化（备用方案，适用于非域终端）

修改以下注册表路径以锁定双面为默认行为（需管理员权限）：

```
HKEY_CURRENT_USER\Software\Microsoft\Windows NT\CurrentVersion\Windows Printing\Printers\HP-M428fdw-Corp\DevMode
```

- 修改 `dmDuplex` 值为 `2`（表示 `DM_DUPLEX_VERTICAL`，即长边翻转）；  
- 修改 `dmFields` 值添加 `0x00000200`（启用 Duplex 字段）；  
- *警告：直接编辑注册表前请备份，错误值可能导致打印服务崩溃（事件查看器错误 ID: `1001`）。*

## 三、故障排查速查表

| 现象                          | 可能原因                     | 解决步骤                                                                 |
|-------------------------------|------------------------------|--------------------------------------------------------------------------|
| 打印时仍为单面，即使已勾选双面 | 驱动未加载双面器模块         | 卸载驱动 → 重装含“Duplex Unit Support”的完整驱动包（非基础版）         |
| 双面打印内容上下颠倒/错位      | 翻转方向设置错误             | 在打印机属性中切换为“短边翻转”（适用于小册子/纵向文档）                 |
| Word 中默认恢复为单面          | Normal.dotm 模板被重置       | 将已配置双面的 Normal.dotm 复制到 `C:\Users\%USERNAME%\AppData\Roaming\Microsoft\Templates\` 并设为只读 |
| 打印队列卡在“正在连接…”        | 打印后台处理服务（Spooler）异常 | 以管理员身份运行：<br>`net stop spooler && del /q %systemroot%\System32\spool\PRINTERS\* && net start spooler` |

---  
✅ **最佳实践建议**：  
- 新员工入职时，通过 Intune 或 SCCM 自动部署预配置打印机驱动 + GPO 策略；  
- 每季度审核一次打印机固件版本（如 HP M428fdw 当前推荐固件：`20231205`），固件升级可修复双面逻辑缺陷（已知问题 ID: `FW-BUG-8821`）。
