# 会议室预订系统与设备联动运维指南

## 概述  
本指南适用于公司内部会议室预订系统（MeetingRoom Booking System, MRBS）与智能硬件（含投影仪、电子白板、AV 控制面板、门禁显示屏及网络打印机）的集成运维场景。重点说明设备状态同步、预约触发联动、故障诊断及常见错误处理流程。

---

## 系统架构简图  
```
[MRBS Web/App]  
       ↓ (REST API / Webhook)  
[中央调度服务] ←→ [IoT 设备网关]  
       ↓                ↓         ↓  
[AV 控制器]    [门禁屏]   [网络打印机]
```

> ✅ 支持协议：HTTP/HTTPS（OAuth2.0 认证）、MQTT（v3.1.1，QoS=1）、SNMPv3（仅用于打印机状态轮询）

---

## 关键联动功能说明  

### 1. 预约开始前 5 分钟自动唤醒设备  
- 投影仪：发送 `POWER ON` + `INPUT HDMI2` 指令（通过 Crestron CP3 控制器）  
- 电子白板：调用 `Wacom Display API v2.4` 启动白板服务并清空临时缓存  
- 打印机：预热并加载「会议签到单」模板（PDF，A4，双面）至内存队列  

### 2. 预约结束自动休眠  
- 若检测到连续 3 分钟无红外人体感应（通过门顶传感器），触发以下动作：  
  - 投影仪 → `POWER OFF`  
  - 白板 → `STANDBY MODE`  
  - 打印机 → 清除待打印任务（保留最近 1 次签到单日志供审计）  

### 3. 异常状态实时同步至 MRBS UI  
| 设备类型 | 状态字段 | 同步方式 | 更新延迟 |
|----------|-----------|------------|-------------|
| 网络打印机 | `toner_level`, `paper_jam`, `offline_reason` | SNMPv3 轮询（60s 间隔） | ≤ 90s |
| AV 控制器 | `hdmi_input_status`, `audio_mute`, `temperature` | MQTT 主题 `mrbs/av/status/{room_id}` | ≤ 5s |
| 门禁屏 | `display_content`, `touch_response_time` | HTTP POST 回调（MRBS 主动拉取） | ≤ 30s |

## 常见故障排查步骤  

### ❗ 打印机未按预约自动加载签到单（错误码：`PRN-ERR-407`）  

1. **确认基础连通性**  
   - 在 MRBS 应用服务器执行：  
     ```bash
     telnet printer-room3.company.local 9100  # 验证端口可达
     snmpget -v3 -u mrbs_user -l authPriv -a SHA -x AES \
             -A "auth_pass" -X "priv_pass" \
             printer-room3.company.local sysDescr.0
     ```

2. **检查模板文件路径与权限**  
   - 模板路径：`/opt/mrbs/templates/checkin_room3_v2.pdf`  
   - 权限要求：`-rw-r--r-- root:mrbs`，SELinux context 必须为 `system_u:object_r:bin_t:s0`

3. **验证调度服务日志**  
   ```bash
   journalctl -u mrbs-print-scheduler -n 50 --since "2 hours ago" | grep -E "(ERROR|407|timeout)"
   ```
   - 典型报错：`Failed to render PDF: font 'NotoSansCJKsc' not found` → 需在容器中安装 `fonts-noto-cjk` 包

4. **手动触发测试任务**  
   ```bash
   curl -X POST https://mrbs-api.company.local/v1/print/trigger \
        -H "Authorization: Bearer $TOKEN" \
        -d '{"room_id":"RM-304","template":"checkin_v2"}'
   ```

5. **重置打印机状态缓存（如仍失败）**  
   ```bash
   redis-cli -h redis-mrbs.company.local DEL "printer:RM-304:cache"
   ```

## 设备固件与接口兼容性清单  

| 设备型号 | 最低固件版本 | 支持协议 | 备注 |
|----------|----------------|-------------|------|
| Epson WorkForce Pro WF-C579R | V4.2.0 | IPP Everywhere, SNMPv3 | 需关闭“节能深度休眠”模式 |
| Crestron CP3 | 3.12.5000 | REST API v2.8, Telnet | 必须启用 `MRBS Integration Mode` |
| SMART Board 6065 | 8.2.137 | Wacom Display API v2.4 | 不支持 Windows Hello 认证直连 |
| Samsung Xpress M3370FD | V1.02.04.00 | AirPrint, SNMPv3 | 仅支持 IPv4，IPv6 会中断状态上报 |

> ⚠️ **重要提示**：所有设备必须配置 NTP 客户端指向 `ntp.company.local`（时差 > 30s 将导致预约时间校验失败，报错 `TIME-SKEW-ERR`）
