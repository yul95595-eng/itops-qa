# 办公设备报废与回收处置流程（打印机与硬件）

> 本流程适用于公司范围内所有已达到使用年限、严重故障无法修复、或因技术升级需淘汰的办公打印设备（含激光/喷墨打印机、多功能一体机、条码打印机、票据打印机等）及配套硬件（如打印服务器、专用耗材管理模块、固态硬盘等）。

---

## 一、报废判定标准

满足以下任一条件，可启动报废流程：

| 判定维度         | 具体标准                                                                 |
|------------------|--------------------------------------------------------------------------|
| **使用年限**     | 激光打印机 ≥ 6年；喷墨一体机 ≥ 4年；工业级票据/条码打印机 ≥ 5年           |
| **维修成本**     | 单次维修费用 ≥ 同型号设备当前市场重置价的 40%，或累计维修次数 ≥ 3 次/年   |
| **功能失效**     | 核心功能（打印/扫描/复印/网络通信）不可恢复性故障，且无原厂备件支持       |
| **安全合规**     | 设备不支持 TLS 1.2+ 加密协议、无法接入公司统一身份认证（LDAP/OAuth2）、存在已知 CVE 高危漏洞且无固件更新 |
| **能效与环保**   | 能效等级低于国家 GB 21520-2015 三级标准，或含汞/铅超标（依据 RoHS 检测报告） |

> ⚠️ 注意：涉及涉密信息处理的设备（如财务/法务部门专用打印机），须额外执行《涉密设备数据清除规范》（见附件 A）。

---

## 二、报废申请与审批流程

### 1. 提交《办公设备报废申请表》（IT-FORM-HW-RETIRE-01）
申请人需完整填写：
- 设备资产编号（贴于设备背面银色标签）
- 品牌/型号/序列号（SN）
- 最后一次维修记录编号（如有）
- 报废原因勾选（附简要说明，≥20字）
- 预估残值（由IT资产管理员协同采购部评估）

### 2. 审批路径（线上OA系统自动流转）
1. 部门负责人审批（1个工作日内）  
2. IT基础设施组初审（核查资产状态、维保记录、是否在网管平台在线）  
3. 公司资产管理委员会终审（每月第1个周三集中审议）  
4. 财务部备案（同步更新固定资产台账）

> ✅ 审批通过后，系统自动生成唯一「报废工单号」（格式：RET-YYYYMMDD-XXXXX），作为后续处置唯一凭证。

## 三、设备回收与物理处置步骤

### 1. 数据安全清除（强制前置步骤）
| 设备类型         | 清除方式                                                                 | 验证要求                     |
|------------------|--------------------------------------------------------------------------|------------------------------|
| 内置硬盘/SSD     | 使用 Blancco Drive Eraser 或 DBAN 执行 DoD 5220.22-M 标准擦除（3轮）     | 提供擦除日志PDF并签名存档    |
| NVRAM/Flash 存储 | 执行厂商指定安全复位指令（如 HP: `*#06# → Security Wipe`；Canon: Service Mode → HDD Format） | 拍摄操作过程视频（≥30秒）    |
| 网络配置存储     | 删除所有IP地址、SNMP社区字符串、LDAP绑定信息，并重置为出厂默认DHCP模式    | Ping 测试确认无法响应旧IP    |

### 2. 物理拆解与分类移交
按以下顺序执行（由持证IT运维工程师操作）：

1. 断电并静置 ≥15 分钟（释放电容残余电压）  
2. 拆卸硒鼓、墨盒、废粉仓——移交至「耗材回收专柜」（标注“含化学物质，禁混投”）  
3. 拆卸主控板、电源模块、电机组件——贴标「电子元器件（含贵金属）」，移交合作回收商A（具备《废弃电器电子产品处理资格证书》）  
4. 外壳塑料/金属部件——分色打包（ABS/PC/铝合金），移交合作回收商B（ISO 14001 认证）  
5. 填写《设备拆解清单》（含各部件重量、去向、接收方签章），扫描上传至资产系统  

> 📌 关键控制点：严禁私自拆解出售；所有移交须双人见证并留存交接影像。

## 四、常见问题与错误码处理

| 错误现象                          | 可能原因                  | 解决方案                                  |
|-----------------------------------|---------------------------|-------------------------------------------|
| 报废工单状态卡在“IT初审”超48h    | 设备未在CMDB中登记或SN不符 | 核对资产标签→联系IT服务台（ext. 8080）补录 |
| Blancco擦除失败报错 `ERR-702`     | SSD启用硬件加密（SED）    | 进入BIOS关闭TPM/Secure Boot，或联系厂商获取解锁密钥 |
| 回收商拒收某批次打印机            | 检测出含汞灯管（老式CCD扫描仪） | 启动《危险废物转移联单》流程（联系EHS部门） |
| OA系统无法提交申请                | 浏览器兼容性问题（仅支持Chrome 115+/Edge 116+） | 切换浏览器或使用IT自助终端机              |
