# 远程会议软件音频/视频问题排查指南

## 概述  
本指南适用于公司内部常用远程会议软件（如腾讯会议、Zoom、钉钉会议、Microsoft Teams）在 Windows/macOS 系统下出现的**音频无声、回声、杂音、视频黑屏、卡顿、无法开启摄像头/麦克风**等常见问题。内容涵盖快速自查、系统级检查、软件配置及典型错误码处理。

---

## 一、基础自查（5分钟内完成）

请按顺序执行以下步骤：

1. **确认物理设备状态**  
   - 检查耳机/麦克风是否插紧（USB/3.5mm 接口），蓝牙设备是否已配对并连接成功；  
   - 摄像头指示灯是否亮起（部分笔记本需按 `Fn + F9/F10` 等组合键启用）；  
   - 尝试在系统自带录音机/相机应用中测试音视频功能是否正常。

2. **检查会议软件权限**  
   | 系统平台 | 需授权项                  | 设置路径（示例）                              |
   |----------|---------------------------|---------------------------------------------|
   | Windows 10/11 | 麦克风、摄像头、后台应用权限 | 设置 → 隐私和安全 → 麦克风/相机 → 允许应用访问 |
   | macOS Ventura+ | 麦克风、摄像头、屏幕录制     | 系统设置 → 隐私与安全性 → 相应权限项 → 勾选会议软件 |

3. **重启会议软件并重新加入会议**  
   - 完全退出（非最小化），清除进程（Windows：`Ctrl+Shift+Esc` → 结束“TencentMeeting.exe”等；macOS：活动监视器中强制退出）；  
   - 重新启动后，**先不入会**，进入「设置 → 音视频」中测试设备。

## 二、常见错误码与对应处理

| 错误码（示例） | 表现现象               | 可能原因                     | 解决方案                                                                 |
|----------------|------------------------|------------------------------|--------------------------------------------------------------------------|
| `ERR_MIC_ACCESS_DENIED` | 麦克风灰显/提示“未授权” | 系统权限被禁用或浏览器策略限制 | 检查系统隐私设置；Chrome 用户需在地址栏点击锁形图标 → “网站设置” → 启用麦克风 |
| `VIDEO_DEVICE_BUSY`     | 摄像头黑屏/提示“设备忙” | 其他程序（如微信、OBS、杀毒软件）占用摄像头 | 关闭所有可能调用摄像头的应用，或在任务管理器中结束 `CameraUI.exe` / `VDCAssistant` 进程 |
| `AUDIO_ECHO_DETECTED`   | 严重回声、啸叫         | 扬声器声音被本地麦克风拾取    | 使用耳机（禁用扬声器）；在会议设置中开启「自动降噪」「抑制回声」；调整麦克风输入音量≤60% |
| `NETWORK_QUALITY_POOR`  | 视频马赛克、频繁掉线    | 上行带宽＜1.2 Mbps 或丢包率＞5% | 关闭下载/云同步/视频流应用；有线连接优先；Wi-Fi 下切换至 5GHz 频段；禁用 QoS 限速策略 |

## 三、进阶修复步骤（适用于反复失败场景）

### 步骤 1：重置音视频驱动配置  
- Windows：  
  ```powershell
  # 以管理员身份运行 PowerShell，逐条执行：
  net stop audiosrv
  net start audiosrv
  # 重启 Windows Audio Endpoint Builder 服务
  ```

### 步骤 2：清除会议软件缓存与配置  
- 腾讯会议：删除 `%appdata%\Tencent\Meeting` 文件夹（Windows）或 `~/Library/Application Support/Tencent/Meeting`（macOS）；  
- Zoom：使用官方[清理工具](https://support.zoom.us/hc/zh-cn/articles/360052707831)（Zoom Cleaner）；  
- **注意：清除后需重新登录账号并重新授权设备。**

### 步骤 3：禁用硬件加速（缓解 GPU 解码异常）  
- 在会议软件「设置 → 通用」中关闭「启用硬件加速」；  
- 若使用 Chrome 浏览器入会：地址栏输入 `chrome://settings/system` → 关闭「使用硬件加速模式（如果可用）」→ 重启浏览器。

## 四、附录：网络与设备最低要求参考

| 项目         | 最低要求                     | 推荐配置                     |
|--------------|------------------------------|------------------------------|
| 上行带宽     | ≥1.2 Mbps（标清视频）         | ≥3.0 Mbps（高清+共享屏幕）    |
| CPU          | Intel Core i3 / AMD Ryzen 3  | Intel Core i5 / AMD Ryzen 5+ |
| 摄像头       | 720p @ 30fps（USB 2.0）        | 1080p @ 30fps（USB 3.0）      |
| 麦克风       | 全向驻极体麦克风（信噪比≥55dB）| 降噪麦克风阵列（支持 AEC）    |

> ⚠️ 提示：若问题持续存在且仅发生在特定会议室终端，请联系 IT 支持核查该终端是否启用「组策略限制音频重定向」或部署了兼容性补丁（如 KB5034441 影响 Win11 23H2 麦克风调用）。
