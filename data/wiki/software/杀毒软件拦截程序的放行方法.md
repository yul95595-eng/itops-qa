# 杀毒软件拦截程序的放行方法（运维 Wiki）

> **适用对象**：IT 运维人员、桌面支持工程师、系统管理员  
> **更新时间**：2024年6月  
> **知识域**：软件与报错  

---

## 一、常见拦截场景说明

杀毒软件（如 Windows Defender、火绒、360安全卫士、腾讯电脑管家、卡巴斯基等）在以下情况下可能误报或主动拦截合法程序：

- 公司内部开发的无数字签名工具（如自动化脚本 `.exe`、批处理封装程序）  
- 使用 UPX 等加壳工具压缩的可执行文件  
- 首次运行的未知来源程序（尤其来自内网共享或本地编译）  
- 启动时访问敏感 API（如 `CreateRemoteThread`、注册表自启动项写入）  
- 程序行为触发启发式引擎（如高频文件读写、内存注入特征）

> ⚠️ 注意：放行 ≠ 关闭防护。应优先确认程序安全性，避免引入真实威胁。

## 二、主流杀毒软件放行操作指南

### 2.1 Windows Defender（Microsoft Defender Antivirus）

#### ✅ 方法一：通过安全中心界面添加排除项（推荐）

1. 打开「Windows 安全中心」 → 「病毒和威胁防护」  
2. 下拉至「管理设置」→ 点击「病毒和威胁防护设置」  
3. 在「排除项」区域点击「添加或删除排除项」  
4. 点击「+ 添加排除项」→ 选择类型：
   - **文件**：指定具体 `.exe` 或 `.dll` 路径（例：`C:\CompanyTools\deploy_tool.exe`）  
   - **文件夹**：适用于整个工具集目录（例：`C:\CompanyTools\`）  
   - **文件类型**：谨慎使用（如 `.ps1`），仅限可信环境  
   - **进程**：按进程名排除（例：`deploy_tool.exe`）  

> 🔍 排查提示：若拦截弹窗中显示“已由 Microsoft Defender 阻止”，可在「保护历史记录」中定位该事件，点击「允许在设备上运行」快速放行。

#### ❌ 常见错误码参考
| 错误码 | 含义 | 解决建议 |
|--------|------|-----------|
| `0x80508016` | 排除项已达上限（默认最多 500 项） | 清理无效排除项，或改用文件夹级排除 |
| `0x80070005` | 权限不足（需以管理员身份运行设置） | 右键「Windows 安全中心」→「以管理员身份运行」 |

### 2.2 火绒安全软件（v5.0+）

| 操作步骤 | 说明 |
|----------|------|
| 1. 右键任务栏火绒图标 →「打开主界面」 | 确保为最新版（检查更新） |
| 2. 进入「防护中心」→「高级防护」→「自定义规则」 | 不要关闭“启用高级防护”总开关 |
| 3. 点击「添加规则」→ 类型选「程序规则」 | |
| 4. 填写：<br>• 规则名称：`公司部署工具放行`<br>• 程序路径：`C:\CompanyTools\*.exe`（支持通配符）<br>• 动作：`放行`<br>• 启用：✅ | ✅ 支持路径通配符与哈希值匹配（提升精准度） |
| 5. 点击「确定」并重启规则引擎（或重启火绒服务） | 执行 `net stop hvsrv && net start hvsrv` |

> 💡 进阶技巧：对关键程序可右键其进程 →「添加到信任区」，自动创建基于文件哈希的白名单。

### 2.3 360安全卫士（13.x 版本）

| 步骤 | 操作要点 |
|------|----------|
| 1. 打开主界面 →「木马查杀」→「隔离区」 | 查找被拦截但确认安全的文件 |
| 2. 右键目标文件 →「添加信任」→「信任此文件」 | 仅对当前文件生效 |
| 3. 若需永久放行：「功能大全」→「安全防护」→「信任区」→「添加文件/文件夹」 | 支持拖拽添加，自动同步至云信任库（企业版可禁用云同步） |
| 4. （企业环境）通过「360企业安全管控平台」下发全局信任策略 | 需管理员权限配置策略组，路径支持 UNC（如 `\\fileserver\tools\**`） |

## 三、通用最佳实践与注意事项

1. **优先使用最小粒度排除**  
   ✅ 推荐：单个 `.exe` 文件 或 可信工具根目录  
   ❌ 避免：`C:\*`、`*.exe` 全局通配

2. **签名与加固建议**  
   - 对内发程序申请 EV 代码签名证书（如 Sectigo、DigiCert）  
   - 使用 `signtool sign /fd SHA256 /tr http://timestamp.digicert.com ...` 签名  
   - 避免 UPX 等通用加壳；确需混淆，建议使用定制化加壳或虚拟化保护（如 VMProtect）

3. **日志审计要求（合规必备）**  
   - 所有放行操作须记录：时间、操作人、程序路径、SHA256 哈希、审批单号  
   - 示例哈希校验命令（PowerShell）：
     ```powershell
     Get-FileHash "C:\CompanyTools\deploy_tool.exe" -Algorithm SHA256 | Select-Object Hash
     ```

4. **批量部署脚本（供域环境参考）**  
   ```powershell
   # 为 Defender 添加文件夹排除（需管理员权限）
   Add-MpPreference -ExclusionPath "C:\CompanyTools\"
   # 验证是否生效
   Get-MpPreference | Select-Object -ExpandProperty ExclusionPath
   ```
