# Windows 系统还原与恢复点使用指南

> **适用系统**：Windows 10 / Windows 11（家庭版、专业版、企业版）  
> **适用场景**：系统异常、驱动冲突、软件安装失败、恶意软件清理后修复、误删关键系统文件等  

---

## 一、系统还原与恢复点基础概念

### 1.1 什么是系统还原（System Restore）？
系统还原是 Windows 内置的**非破坏性恢复机制**，它通过创建并保存系统关键状态（注册表、系统文件、已安装程序、驱动配置等）的快照（即“恢复点”），在系统故障时将系统回退至该时间点的状态。  
⚠️ 注意：  
- 不影响个人文件（如文档、图片、桌面文件等）；  
- 可能卸载还原点创建后安装的程序、驱动或 Windows 更新；  
- **无法恢复已删除的个人数据**（需依赖备份工具如 File History 或第三方备份软件）。

### 1.2 恢复点（Restore Point）类型
| 类型 | 触发方式 | 是否可手动创建 | 说明 |
|------|-----------|----------------|------|
| **自动创建** | Windows Update、程序安装（含 MSI 安装包）、驱动更新、系统设置变更 | 否 | 默认启用，由 `SR`（System Restore）服务管理；通常每 7 天自动创建一次（若未触发其他事件） |
| **手动创建** | 用户主动执行 | 是 | 推荐在重大操作前（如升级大版本、安装新驱动/杀毒软件）创建 |
| **检查点恢复点** | Windows Defender 实时防护检测到高风险行为（如勒索软件加密行为） | 否 | 自动触发，用于快速回滚恶意修改 |

## 二、启用与配置系统还原

> ✅ 前提：系统盘（通常是 `C:`）必须为 NTFS 格式，且磁盘空间充足（建议预留 ≥ 5GB 可用空间）

### 步骤：启用系统还原并分配最大磁盘空间
1. 右键「此电脑」→ 选择「属性」→ 左侧点击「系统保护」；  
2. 在「系统属性 → 系统保护」选项卡中，选中系统盘（如 `C:`），点击「配置」；  
3. 选择「启用系统保护」；  
4. 拖动「最大使用量」滑块，建议设置为 **5%～10%**（例如 100GB 系统盘设为 5–10GB）；  
5. 点击「确定」→ 「应用」→ 「确定」完成配置。

> 🔍 验证是否启用：在「系统保护」选项卡中，对应磁盘状态应显示为「已启用」，且「磁盘空间使用量」有数值。

## 三、创建与管理恢复点

### 3.1 手动创建恢复点（推荐操作）
1. 打开「控制面板」→「系统和安全」→「系统」→「系统保护」；  
2. 选中系统盘 → 点击「创建」；  
3. 输入描述名称（如 `Win11升级前_20240520`），点击「创建」；  
4. 等待提示「创建完成」（通常耗时 1–3 分钟，取决于系统变更量）。

### 3.2 查看与删除旧恢复点
- 在「系统保护」选项卡中点击「系统还原…」→ 进入向导后点击「下一步」→ 可查看所有可用恢复点及时间戳；  
- 如需释放空间：回到「系统保护」→ 选中磁盘 → 「配置」→ 「删除」（⚠️ 此操作**永久清除该磁盘所有旧恢复点，仅保留最新一个**）。

## 四、执行系统还原（三种常用方式）

### 方式一：正常启动下还原（适用于可登录系统）
1. 搜索并打开「创建还原点」→「系统还原…」；  
2. 点击「下一步」→ 选择目标恢复点（建议勾选「扫描受影响的程序」以预览变更）；  
3. 确认后点击「完成」→ 系统提示重启，点击「是」；  
4. 还原过程自动进行（约 10–30 分钟），完成后自动进入桌面。

### 方式二：高级启动环境（AEF）下还原（适用于无法正常启动）
1. 强制关机 3 次（开机后立即断电），第 4 次开机将自动进入「自动修复」界面；  
   *或*  
   使用 Windows 安装介质/U 盘启动 →「修复计算机」→「疑难解答」→「高级选项」→「系统还原」；  
2. 选择账户并输入密码（如有）；  
3. 按向导选择恢复点 → 执行还原。

### 方式三：命令行强制还原（管理员权限 PowerShell）
```powershell
# 列出所有可用恢复点
rstrui.exe

# 或使用 WMI 查询（需管理员权限）
Get-ComputerRestorePoint | Sort-Object CreationTime -Descending | Format-Table CreationTime,Description,SequenceNumber
```

## 五、常见问题与错误码处理

| 错误现象 | 可能原因 | 解决方案 |
|----------|-----------|------------|
| **“系统还原未启用”或“找不到任何恢复点”** | 系统保护被禁用；磁盘空间不足；恢复点被手动/自动清理 | 检查「系统保护」状态；清理磁盘空间后重新启用；确认未执行过 `vssadmin delete shadows` 命令 |
| **还原过程中报错 0x80070091（目录不是空的）** | 第三方安全软件（如某些国产杀软）阻止 VSS 服务写入 | 临时禁用实时防护，或在安全模式下执行还原 |
| **还原后网络不可用/驱动丢失** | 还原点创建时网卡驱动未正确加载，或驱动签名强制策略干扰 | 进入「设备管理器」→ 更新网络适配器驱动；或执行 `sfc /scannow` + `DISM /Online /Cleanup-Image /RestoreHealth` |
| **“系统还原无法访问还原点”（错误 0x80070005）** | 权限不足或系统卷影复制服务（VSS）异常 | 以管理员身份运行：<br>`net stop vss`<br>`net start vss`<br>`net start swprv` |

## 六、最佳实践建议

1. **定期创建手动恢复点**：每次重大操作前（如 Windows 功能更新、BIOS 升级、更换显卡驱动）；  
2. **禁用对非系统盘启用系统保护**：避免无谓占用 SSD 空间（系统还原不支持 D/E 盘独立还原）；  
3. **配合使用其他恢复手段**：  
   - 启用「文件历史记录」（File History）保护个人文档；  
   - 创建「系统映像备份」（控制面板 → 备份和还原 → 创建系统映像）用于整盘灾难恢复；  
4. **禁用第三方“一键还原”工具冲突**：部分 OEM 厂商工具（如 Lenovo OneKey Recovery）可能与 Windows SR 服务竞争资源，建议优先使用原生功能。
