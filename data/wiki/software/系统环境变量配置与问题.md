# 系统环境变量配置与问题排查指南

> 本文档适用于公司内部 Linux/Windows 服务器及开发终端的环境变量配置、验证与常见报错处理，覆盖 JDK、Python、Node.js、Maven 等主流工具链。

---

## 一、环境变量基础概念

环境变量是操作系统为进程提供的一组动态命名值，用于控制程序运行时的行为（如可执行文件搜索路径 `PATH`、Java 运行时目录 `JAVA_HOME`、项目根路径 `PROJECT_ROOT` 等）。

### 关键变量说明

| 变量名         | 典型用途                             | 推荐设置方式           |
|----------------|--------------------------------------|------------------------|
| `PATH`         | 指定命令搜索路径（多个路径用 `:` 或 `;` 分隔） | 追加，避免覆盖系统默认值 |
| `JAVA_HOME`    | JDK 安装根目录（JVM 启动必需）        | 必须指向 JDK 根目录（非 `bin/`） |
| `PYTHONPATH`   | Python 模块额外搜索路径              | 开发调试时按需设置     |
| `NODE_ENV`     | Node.js 运行环境标识（`development`/`production`） | 非全局变量，建议在启动脚本中导出 |
| `MAVEN_HOME`   | Maven 安装路径                       | 配合 `PATH` 添加 `$MAVEN_HOME/bin` |

> ⚠️ 注意：  
> - Linux/macOS 区分大小写；Windows 不区分但建议统一小写风格。  
> - 修改后需**重新加载 Shell**（`source ~/.bashrc`）或**重启终端/会话**生效。  
> - Windows 中通过「系统属性 → 高级 → 环境变量」配置，**用户变量优先于系统变量**。

## 二、典型配置步骤（以 Linux 为例）

### 1. 配置 JDK 环境变量（OpenJDK 17）

```bash
# 步骤 1：确认 JDK 安装路径（例如 /opt/java/jdk-17.0.2）
$ ls -l /opt/java/
drwxr-xr-x 8 root root 4096 Mar 15 10:22 jdk-17.0.2/

# 步骤 2：编辑用户级配置文件
$ vim ~/.bashrc

# 步骤 3：追加以下内容（注意路径与版本匹配）
export JAVA_HOME=/opt/java/jdk-17.0.2
export PATH=$JAVA_HOME/bin:$PATH

# 步骤 4：立即生效
$ source ~/.bashrc

# 步骤 5：验证
$ java -version
$ echo $JAVA_HOME
```

### 2. 配置 Maven（3.9.x）

```bash
# 下载解压后（如 /opt/maven/apache-maven-3.9.6）
export MAVEN_HOME=/opt/maven/apache-maven-3.9.6
export PATH=$MAVEN_HOME/bin:$PATH
```

## 三、常见报错与解决方案

| 错误现象                          | 可能原因                                                                 | 解决方案                                                                 |
|-----------------------------------|--------------------------------------------------------------------------|--------------------------------------------------------------------------|
| `command not found: java`         | `PATH` 未包含 `$JAVA_HOME/bin`；或 `JAVA_HOME` 未设置                    | 检查 `echo $PATH` 是否含 `java` 路径；确认 `JAVA_HOME` 指向正确目录       |
| `Error: Could not find or load main class ...` | `JAVA_HOME` 指向了 JRE 或错误子目录（如 `/jdk-17.0.2/jre/`）              | `JAVA_HOME` 必须为 JDK 根目录（含 `bin/`、`lib/`、`jmods/` 等子目录）     |
| `mvn: command not found`          | `MAVEN_HOME` 未配置，或 `PATH` 未添加 `$MAVEN_HOME/bin`                  | 执行 `ls $MAVEN_HOME/bin/mvn` 确认存在；修正 `PATH` 设置                 |
| Python 模块 `ImportError`         | `PYTHONPATH` 缺失或路径拼写错误；或 `.pyc` 缓存未更新                     | 检查 `echo $PYTHONPATH`；运行 `python -c "import sys; print(sys.path)"`；清理 `__pycache__` |
| Windows 下 `The system cannot find the path specified.` | 环境变量含中文、空格或特殊字符（如 `C:\Program Files\Java\...`）         | 使用短路径（`PROGRA~1`）或双引号包裹路径（`"C:\Program Files\Java\..."`） |

## 四、诊断命令速查表

| 场景                         | 命令                                      | 说明                                     |
|------------------------------|-------------------------------------------|------------------------------------------|
| 查看所有环境变量             | `env` 或 `printenv`                       | Linux/macOS                              |
| 查看单个变量值                 | `echo $PATH` / `echo %PATH%`（Win）        | 注意 `$` 符号不可省略                      |
| 检查命令实际解析路径           | `which java` / `where java`（Win）         | 验证 `PATH` 是否生效                      |
| 查看 Java 实际加载路径         | `java -XshowSettings:properties -version 2>&1 \| grep java.home` | 输出 JVM 加载的 `java.home`（非 `JAVA_HOME`） |
| 检查是否为 shell 内置变量      | `type -a export` / `set | grep JAVA_HOME` | 排除别名或函数干扰                         |

## 五、最佳实践建议

1. ✅ **统一管理**：将环境变量配置集中到 `~/.bashrc`（Linux/macOS）或用户级系统变量（Windows），避免多处重复。
2. ✅ **路径校验**：配置前先 `ls -d $YOUR_PATH` 确认目录真实存在且有执行权限。
3. ✅ **版本锁定**：生产环境禁止使用 `JAVA_HOME=/usr/lib/jvm/default-java` 等软链接路径，应硬编码具体版本路径。
4. ❌ **禁止操作**：
   - 直接 `export PATH=/new/path`（覆盖原 `PATH`，导致 `ls`、`cd` 失效）；
   - 在 `/etc/profile` 中为单用户配置（应使用 `~/.bashrc`）；
   - 将敏感信息（如 API Key）明文写入环境变量文件（应使用 secrets 工具或 CI/CD 注入）。
