# 软件白名单申请与安装流程

> **适用对象**：公司全体员工（含外包人员）  
> **适用系统**：Windows 10/11（企业版）、Windows Server 2016/2019/2022  
> **生效范围**：全公司终端设备（含虚拟桌面VDI环境）  
> **更新日期**：2024年10月15日  

---

## 一、背景说明

为保障公司终端安全与合规性，IT 部门实施「软件执行控制策略」（Application Control Policy），默认禁止未授权软件的安装与运行。所有需在工作设备上部署的第三方或非标准办公类软件（如开发工具、数据处理工具、专业设计软件等），须通过**软件白名单审批流程**后方可安装。

⚠️ 注意：  
- 系统自带应用（如 Microsoft Edge、Notepad++ 企业预装版）、OA/ERP 客户端、杀毒软件（已由IT统一部署）无需单独申请；  
- 未经审批擅自安装/运行非白名单软件，将触发终端安全告警，并可能被自动阻断进程或隔离设备。

---

## 二、白名单申请流程（线上化）

### 步骤 1：填写《软件白名单申请表》
登录公司 IT 服务门户 → 进入【软件管理】→ 【白名单申请】→ 填写以下必填信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 申请人 | 员工工号+姓名 | `E123456_张三` |
| 所属部门 | 标准组织架构名称 | `研发中心-大数据平台部` |
| 软件名称及版本 | 精确到主版本号 | `Python 3.11.9 (64-bit)` |
| 安装包来源 | 必须为官网/可信渠道 | `https://www.python.org/downloads/` |
| 用途说明 | 不少于30字，说明业务必要性 | `用于ETL任务调度脚本开发与本地测试，替代原Shell方案，提升数据解析稳定性` |
| 是否含管理员权限需求 | 是/否（影响安装方式） | `是` |
| 是否含网络外联行为 | 是/否（需安全评估） | `是（仅连接公司内部API网关）` |

✅ 提交前请确认：  
- 已下载官方签名安装包（`.exe`/`.msi` 文件需带有效数字签名）；  
- 若为绿色版/便携版，需额外提供《免安装软件安全承诺书》（模板见附件链接）。

### 步骤 2：IT 安全组初审（T+1 工作日内）
- 检查软件来源合法性、数字签名有效性、已知漏洞（CVE）情况；  
- 对含外联行为的软件，同步推送至网络安全组进行流量策略评估。

### 步骤 3：终审与入库（T+2 工作日内）
- 审批通过后，软件将录入公司「终端软件白名单库」，并生成唯一白名单ID（格式：`SW-YYYYMMDD-XXXXX`）；  
- 系统自动向申请人邮箱发送《白名单授权通知》，含安装指引与校验码。

---

## 三、获准后的安装方式

根据终端环境与软件类型，选择以下任一方式安装：

### ✅ 方式 A：IT 统一分发（推荐｜适用于 Windows 域环境）
1. 登录公司软件分发平台（`softdepot.company.local`）；  
2. 输入白名单ID（如 `SW-20241015-00231`）；  
3. 下载经IT签名加固的安装包（文件名含 `_IT-SIGNED` 后缀）；  
4. 双击运行，按提示完成安装（无需本地管理员权限）。

### ✅ 方式 B：自助安装（需临时提权）
1. 打开「控制面板 → 用户账户 → 管理用户账户」；  
2. 点击「使用我的管理员账户为此计算机上的其他用户提权」；  
3. 输入IT提供的临时提权码（有效期2小时，见邮件正文）；  
4. 运行原始官网安装包（需校验 SHA256 值与邮件中一致）。

### ❌ 禁止操作（将导致安装失败或安全拦截）
- 使用破解版、汉化补丁、第三方下载站安装包；  
- 关闭 Windows Defender 或禁用 SmartScreen；  
- 通过 PowerShell 绕过执行策略（如 `Set-ExecutionPolicy Bypass -Scope Process`）。

## 四、常见报错与处理

| 错误现象 | 错误代码/日志片段 | 原因分析 | 解决方案 |
|----------|-------------------|----------|----------|
| 安装程序启动即退出 | `Event ID 1001: AppLocker blocked execution` | 未通过白名单审批或ID未同步至本地策略 | 检查邮件是否收到授权通知；联系 IT 服务台确认策略同步状态（命令：`gpupdate /force`） |
| 提示“无法验证发布者” | `0x800B010A (TRUST_E_NOSIGNATURE)` | 安装包数字签名无效或证书链不完整 | 重新下载官网正版安装包；勿使用迅雷等第三方下载器 |
| 安装后无法运行 | `Error 0xc00007b` | 32/64位架构不匹配或VC++运行库缺失 | 下载对应架构的 [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe) 并安装 |
| 白名单ID校验失败 | `Invalid SW-ID format or expired` | 手动输入错误或授权已过期（超90天未安装） | 复制邮件原文中的ID；若超期，请重新提交申请 |
