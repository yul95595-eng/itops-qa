# 电脑弹出广告与恶意软件处理指南

## 概述  
本指南适用于公司员工在日常办公中遇到的**非预期弹窗广告、浏览器首页劫持、搜索重定向、CPU/内存异常占用、新标签页自动打开推广页面**等典型恶意软件（Malware）或广告软件（Adware）感染现象。该类问题通常由捆绑安装的免费软件、钓鱼网站下载、或过期插件引发，虽不直接窃取账号密码，但严重影响办公效率与终端安全。

---

## 常见症状识别

| 现象类型         | 典型表现                                                                 | 可能原因                     |
|------------------|--------------------------------------------------------------------------|------------------------------|
| 浏览器异常       | Chrome/Firefox/Edge 首页被篡改为 `hao123.com`、`2345.com` 或未知推广站；搜索结果中夹杂大量“推广链接” | 浏览器扩展劫持、HOSTS 文件篡改 |
| 弹窗频发           | 即使未打开浏览器，桌面右下角/任务栏频繁弹出“系统优化”“杀毒提醒”“中奖通知”等窗口                        | 捆绑式广告程序（如 `BaiduBar`、`PCManager`） |
| 网络行为异常       | 访问内网系统（如 OA、ERP）时跳转至第三方广告页；HTTPS 页面出现“不安全”警告                              | 中间人代理劫持（如 `127.0.0.1:8888` 本地代理） |
| 系统性能下降       | 后台进程 `svchost.exe`、`dllhost.exe` 或未知 `.exe` 占用 CPU >70% 持续 5 分钟以上                         | 挖矿木马（XMRig）、远程控制后门（DarkComet 变种） |

> ⚠️ 注意：若同时出现 **文件被加密 + 勒索信弹窗（如 `.locky`、`.crypt` 后缀）**，请立即断网并联系 IT 安全部——此为勒索病毒，不在本流程覆盖范围。

## 应急处置流程（Windows 系统）

### 步骤 1：立即终止可疑进程  
1. 按 `Ctrl + Shift + Esc` 打开【任务管理器】 → 切换到「详细信息」选项卡  
2. 按 **CPU** 或 **磁盘** 列排序，查找以下高危进程名（大小写不敏感）：  
   - `adserv.exe`, `adwcleaner.exe`, `browserprotect.exe`, `winupdater.exe`  
   - 名称含 `optimizer`、`cleaner`、`secure` 但**无数字签名**或发布者为 `Unknown` 的进程  
3. 右键 → 「结束任务」→ 记录进程路径（如 `C:\Users\Public\Temp\adserv.exe`）

### 步骤 2：清除浏览器劫持项  
| 浏览器 | 清理路径（需逐项检查）                                                                 |
|--------|--------------------------------------------------------------------------------------|
| Chrome | `设置 → 扩展程序` → 禁用/删除来源不明扩展；`设置 → 启动时` → 检查是否被添加非法网址；`设置 → 外观 → 主页` → 还原为 `about:blank` 或公司指定首页 |
| Edge   | `设置 → Cookie 和网站权限 → 管理和删除网站数据` → 勾选「所有时间」→「删除」；`设置 → 重置设置 → 将设置恢复为默认值`（保留收藏夹） |
| Firefox| `地址栏输入：about:addons` → 删除非官方扩展；`about:config` → 搜索 `browser.startup.homepage`，双击重置为 `about:home` |

### 步骤 3：扫描与清理  
使用公司统一部署的 **Microsoft Defender Offline Scan**（离线扫描）执行深度查杀：  
1. 在「开始菜单」搜索并打开 **Windows 安全中心** → 「病毒和威胁防护」  
2. 点击「扫描选项」→ 选择 **「Microsoft Defender 脱机扫描」** → 「立即扫描」  
3. 系统将重启进入离线环境（约 15 分钟），自动清除启动级顽固木马（如 `TDL4`、`ZeroAccess`）  

> ✅ 补充工具（仅限 IT 支持人员启用）：  
> - `AdwCleaner`（Malwarebytes 出品）：专清广告软件，运行后生成 `AdwCleaner[C1].txt` 日志供分析  
> - `RKill`：终止恶意进程后再运行杀软，避免拦截  

### 步骤 4：修复系统配置  
- **检查 HOSTS 文件**：用记事本以管理员身份打开 `C:\Windows\System32\drivers\etc\hosts`，删除所有非注释行（即不含 `#` 开头）的 IP 域名映射，仅保留：  
  ```text
  127.0.0.1 localhost
  ::1 localhost
  ```
- **重置网络代理**：  
  `Win+R` → 输入 `inetcpl.cpl` → 「连接」→ 「局域网设置」→ 取消勾选「为 LAN 使用代理服务器」

## 预防措施（全员必读）

1. **安装软件原则**：  
   - 仅从官网（如 `https://git-scm.com/`、`https://notepad-plus-plus.org/`）下载，**拒绝“高速下载”按钮**（实际为捆绑包）  
   - 安装时务必取消勾选「安装 XX 工具栏」「设为默认搜索引擎」等隐藏选项  

2. **浏览器加固**：  
   - Chrome：启用「增强型保护」（设置 → 隐私设置和安全性 → 安全性）  
   - 禁用 Flash 插件（已淘汰，存在严重 0day 漏洞）  

3. **定期维护**：  
   - 每月执行一次「磁盘清理」→ 勾选「临时 Internet 文件」和「缩略图」  
   - 每季度在 Windows 安全中心运行「全面扫描」

## 常见错误码参考

| 错误提示（弹窗/日志）          | 含义说明                          | 解决方向                     |
|-------------------------------|-----------------------------------|----------------------------|
| `Error 0x80070422`            | Windows Update 服务被禁用/损坏      | 运行 `services.msc` → 启用 `Windows Update` 服务 |
| `Failed to load extension ...` | 浏览器加载了损坏/恶意扩展           | 进入 `chrome://extensions/` → 删除异常 ID 扩展     |
| `Your browser is managed by your organization` | 组策略强制配置（正常，非感染）     | 联系 IT 核实策略下发状态        |

> 📌 **上报要求**：若按本流程操作后 24 小时内仍反复出现弹窗，请通过公司 ITSM 系统提交工单，标题注明【恶意软件复发-设备号 XXX】，并附上：  
> - `AdwCleaner` 日志截图  
> - 任务管理器「详细信息」页 CPU 排序截图  
> - 弹窗文字完整内容（勿打码）
