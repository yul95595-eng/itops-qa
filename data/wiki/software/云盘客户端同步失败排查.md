# 云盘客户端同步失败排查指南

> **适用范围**：公司自研/第三方云盘客户端（如：Nextcloud Desktop Client、Seafile Client、自研WebDAV同步客户端）  
> **适用版本**：v3.2.0 及以上（Windows/macOS/Linux）  
> **最后更新**：2024-06-15  

---

## 一、常见现象与初步定位

当用户反馈「文件未同步」「状态栏显示暂停/错误」「修改后不自动上传」时，请按以下顺序快速判断：

| 现象 | 可能原因 | 优先级 |
|------|----------|--------|
| 同步图标常驻「暂停」状态 | 账户离线、手动暂停、磁盘空间不足 | ⭐⭐⭐⭐ |
| 显示「同步中」但进度长期为0% | 网络代理阻断、SSL证书校验失败、服务端限流 | ⭐⭐⭐⭐ |
| 文件显示「冲突」或「已忽略」 | 文件名含非法字符（如 `?`, `<`, `*`, `:`）、路径过长（>260字符 Windows）、NTFS权限异常 | ⭐⭐⭐ |
| 日志中反复出现 `HTTP 423 Locked` | 服务端文件被其他客户端/网页端加锁（如在线编辑中） | ⭐⭐ |
| 日志中出现 `Error 0x80070005`（Windows） | 客户端无写入权限（如同步目录位于受保护系统路径） | ⭐⭐⭐ |

## 二、标准化排查步骤

### 步骤 1：确认基础运行状态
1. 检查客户端是否处于「已登录」且「账户状态正常」（非密码过期/账号禁用）  
2. 查看系统托盘图标右键菜单 → 确认「暂停同步」未被勾选  
3. 打开客户端设置 → 「同步」页签 → 验证目标文件夹路径存在且可读写（尝试新建测试文件）  
4. 检查本地磁盘剩余空间 ≥ 同步库总大小 × 1.2（预留缓存与临时文件）

### 步骤 2：验证网络连通性
```bash
# 测试基础连接（以典型云盘域名为例）
ping cloud.company.com
curl -I https://cloud.company.com/status.php  # 应返回 HTTP 200
telnet cloud.company.com 443  # 确认端口可达（若失败，检查防火墙/代理）
```
> ✅ 正常响应示例：`HTTP/1.1 200 OK`  
> ❌ 异常响应示例：`curl: (35) SSL connect error` → 检查系统时间是否偏差 >3分钟 或 根证书是否缺失

### 步骤 3：提取并分析客户端日志
- **Windows**：`%LOCALAPPDATA%\CompanyCloud\logs\sync.log`  
- **macOS**：`~/Library/Application Support/CompanyCloud/logs/sync.log`  
- **Linux**：`~/.config/company-cloud/logs/sync.log`

重点关注最近 1 小时内含以下关键词的 ERROR/WARN 行：
- `Failed to upload`
- `Connection refused`
- `SSL certificate verify failed`
- `Locked by another client`
- `Path too long`

### 步骤 4：复现并隔离问题文件
1. 在同步根目录下新建测试文件 `test_sync_$(date +%s).txt`  
2. 观察是否成功上传（服务端 Web 界面刷新确认）  
   - ✅ 成功 → 问题文件可能含特殊字符/权限问题 → 使用 [工具：`check_filename.py`](https://wiki.company/internal/tools/check_filename) 扫描异常路径  
   - ❌ 失败 → 全局同步故障 → 跳转至【三、典型错误码速查】

## 三、典型错误码速查表

| 错误码 / 关键词 | 含义 | 解决方案 |
|----------------|------|-----------|
| `HTTP 401 Unauthorized` | 认证失败（Token 过期/密码变更） | 重新登录客户端；检查单点登录（SSO）会话是否超时 |
| `HTTP 403 Forbidden` | 权限不足（如仅只读共享链接） | 检查该文件夹在服务端的 ACL 设置；联系管理员授权 `write` 权限 |
| `HTTP 423 Locked` | 文件被锁定（如网页端正在编辑 Office 文档） | 等待网页端关闭编辑器；或服务端执行 `occ files:unlock --all`（需管理员权限） |
| `Win32 Error 5` (`0x00000005`) | 访问被拒绝（Windows UAC 或 NTFS ACL 限制） | 右键同步目录 → 属性 → 安全 → 编辑 → 为当前用户添加「完全控制」 |
| `SSL routines::ssl3_get_record:wrong version number` | SSL/TLS 协议版本不匹配（常见于老旧代理） | 客户端设置中启用「使用系统代理」→ 改为「不使用代理」或升级 TLS 至 1.2+ |

## 四、附录：快速修复命令（管理员适用）

```bash
# 【Windows】重置客户端配置（保留账户信息，清除同步状态）
& "$env:LOCALAPPDATA\CompanyCloud\uninstall.exe" /reset-sync-state

# 【macOS/Linux】清除缓存并重启（不影响已同步文件）
rm -rf ~/.cache/company-cloud/*
pkill -f "company-cloud-client"
open -a "Company Cloud"  # macOS
```

> ⚠️ 注意：执行前请确保用户已备份重要未同步文件（如桌面/文档中新增但未上传的文档）
