# 专业软件许可证申请与激活

> 本文档适用于公司内部 IT 运维人员、软件采购负责人及终端用户，涵盖主流专业软件（如 Adobe Creative Cloud、Autodesk 系列、JetBrains 全家桶、MATLAB、SolidWorks 等）的许可证申请、分发、激活及常见报错处理流程。

---

## 一、许可证类型说明

| 许可证类型 | 适用场景 | 授权方式 | 有效期 | 管理特点 |
|------------|----------|-----------|---------|-----------|
| **永久许可（Perpetual License）** | 一次性购买，长期使用（通常含首年免费升级） | 序列号 + 激活服务器校验（或离线激活） | 无自然到期日（但技术支持/更新可能受限） | 需手动记录序列号与绑定设备，升级需额外付费 |
| **订阅许可（Subscription License）** | 按月/年付费，持续获得更新与云服务 | 账户绑定 + 在线身份验证（OAuth / SSO） | 到期自动失效，支持续订 | 依赖网络连接；支持集中管理（如 Autodesk Account、Adobe Admin Console） |
| **浮动许可证（Floating License）** | 多用户共享有限并发数（如实验室、设计中心） | 本地 License Server（如 FlexNet/FNPL、Reprise RLM） | 依采购合同约定（通常按年） | 需部署并维护 License Server；需监控并发使用率与超限告警 |

> ⚠️ 注意：自 2023 年起，Autodesk 已全面停止销售永久许可；MATLAB 自 R2022b 起对高校客户默认启用在线账户绑定激活；SolidWorks 2024+ 强制要求 SOLIDWORKS ID 登录。

## 二、标准申请与激活流程（以企业批量部署为例）

### 1. 许可证申请（采购后 1–3 个工作日内完成）

1. **确认采购凭证**  
   - 核对合同编号、软件名称、版本、数量、授权类型、生效日期；
   - 获取厂商提供的「License Certificate」PDF 或电子密钥文件（如 `.lic`、`.txt`、`activation code`）。

2. **创建企业授权账户**  
   - 在厂商管理平台注册/登录统一管理员账号（如：[Adobe Admin Console](https://adminconsole.adobe.com)、[Autodesk Account](https://accounts.autodesk.com)）；
   - 绑定公司邮箱域（如 `@company.com`），启用 SSO（推荐 Azure AD / Okta 集成）。

3. **导入许可证并分配**  
   - 上传序列号或订阅包（`.zip` 或 `.json`）；
   - 按部门/角色/项目创建用户组（如 `Engineering-CAE`, `Design-CC`）；
   - 批量分配许可证至用户邮箱或设备 MAC 地址（浮动许可需预登记客户端主机名）。

### 2. 客户端激活（终端用户操作）

| 软件类型 | 激活方式 | 关键操作提示 |
|----------|-----------|----------------|
| **Adobe CC** | 在线账户激活 | 启动任意 App → 登录 Adobe ID → 自动同步授权；若失败，运行 [Creative Cloud Cleaner Tool](https://helpx.adobe.com/creative-cloud/kb/cc-cleaner-tool-installation-problems.html) 清理残留 |
| **Autodesk（2023+）** | SSO 绑定激活 | 必须使用公司邮箱登录；首次启动弹出浏览器窗口完成 SSO；禁用广告拦截插件（否则 OAuth 流程中断） |
| **JetBrains（v2023.3+）** | 账户令牌激活 | `Help → Register → Activate with JetBrains Account`；支持离线机器通过「Activation Code」或「License Server URL」激活 |
| **MATLAB R2023a+** | Online Activation via MathWorks Account | 启动 MATLAB → `Sign In` → 输入公司邮箱 → 接收 MFA 验证 → 自动绑定已购 License；若提示 `License Manager Error -9`，检查系统时间是否同步（NTP） |
| **SolidWorks 2024** | SOLIDWORKS ID + Local Activation | 安装后首次运行必须登录 [SOLIDWORKS ID](https://www.solidworks.com/sw/solidworks-id)；离线环境需提前导出「Offline Activation Request File」并上传至官网获取响应文件 |

## 三、高频报错代码与处置指南

| 错误码 / 提示信息 | 可能原因 | 解决方案 |
|-------------------|-----------|------------|
| **`Error 15106`（Adobe）** | 权限不足导致安装器无法写入 `C:\Program Files\Common Files\Adobe\OOBE\PDApp` | 以管理员身份运行 Creative Cloud Desktop App；关闭第三方安全软件临时防护 |
| **`License checkout failed (-97,121)`（MATLAB）** | License Server 不可达或端口被防火墙拦截（默认 TCP 27000） | 检查 `lmutil lmstat -a -c <port>@<server>` 连通性；开放 Windows Defender 防火墙入站规则 |
| **`FlexNet Licensing error:-15,570`（ANSYS / SolidWorks）** | 浮动许可服务器未启动，或 `license.dat` 中 SERVER 行 IP/端口配置错误 | 运行 `rlm -c license.dat -dlog rlm.log` 启动服务；确认 `SERVER hostname 000000000000 27000` 中 MAC 地址与实际网卡一致 |
| **`Invalid activation code`（JetBrains）** | 激活码已过期、被吊销，或输入含不可见空格/全角字符 | 复制激活码时使用纯文本编辑器（如 Notepad++）清理格式；联系 IT 管理员在 [JetBrains License Portal](https://account.jetbrains.com/licenses) 查看状态 |
| **`Your subscription has expired`（Autodesk）** | 订阅已过期或未成功同步至本地缓存 | 打开 Autodesk Desktop App → `Settings → Diagnostics → Reset Application Data`；重启后重新登录 |

> 🔁 **通用重置建议（激活失败时）**：  
> 1. 清除本地授权缓存目录（例：`%LOCALAPPDATA%\JetBrains\IntelliJ IDEA<ver>\options\eval`）；  
> 2. 删除厂商专用证书存储（如 Adobe：`%APPDATA%\Adobe\SLStore`）；  
> 3. 运行 `ipconfig /flushdns` + `net stop wlansvc && net start wlansvc`（重置网络栈）；  
> 4. **最后手段**：卸载 → 使用官方清理工具 → 重启 → 重装。

## 四、合规与审计要点

- ✅ 所有许可证必须留存采购合同、发票、授权证书 PDF 原件，归档于公司知识库「Software-Licenses」目录；
- ✅ 每季度执行一次许可证使用盘点（通过厂商后台导出 `Active Users` / `Checked Out Licenses` 报表）；
- ✅ 禁止跨部门/项目混用订阅许可；禁止将浮动许可客户端注册至非授权 License Server；
- ❌ 不得使用破解补丁、KMS 激活工具或共享个人账户——违反《计算机软件保护条例》第24条，可能导致法律追责与审计否决。
