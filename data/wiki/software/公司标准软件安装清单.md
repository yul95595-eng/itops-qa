# 公司标准软件安装清单

> 本文档定义公司终端（Windows 10/11、macOS 12+）的标准化软件部署规范，适用于新员工入职设备初始化、重装系统后恢复及批量运维场景。所有软件须通过公司内部软件分发平台（SDP）或经IT安全团队审核的离线包安装，禁止私自下载第三方来源软件。

---

## 一、基础办公套件（强制安装）

| 软件名称         | 版本要求       | 安装方式       | 备注说明 |
|------------------|----------------|----------------|----------|
| Microsoft 365 Apps（商业版） | 最新稳定版（含Word/Excel/PowerPoint/Outlook） | SDP自动推送 + 组策略部署 | 需绑定公司Azure AD账户，启用DLP策略 |
| Zoom Workplace   | ≥6.0.0         | SDP静默安装    | 预配置公司SSO登录、禁用本地录制、启用E2EE |
| Slack（企业版）  | ≥4.35.0        | MSI（Win）/PKG（macOS） | 集成Okta SSO，工作区预设为`company.slack.com` |
| Google Chrome    | ≥124.0.6367    | 策略模板管控安装 | 强制启用HTTPS-First Mode，预置公司扩展（如SAML tracer、密码管理器） |

## 二、开发与运维工具（按角色选装）

### 2.1 开发人员（Dev）
- **VS Code**：≥1.88.0，预装扩展包 `company-dev-pack.vsix`（含ESLint、Prettier、GitLens、Azure Account）
- **Git for Windows** / **Git for macOS**：≥2.44.0，全局配置 `core.autocrlf=true`（Win）或 `input`（macOS）
- **Docker Desktop**：≥4.28.0，启用WSL2后端（Win）或Rosetta 2兼容模式（macOS）
- **Postman**：≥10.22.0，导入公司API集合与环境变量模板（`company-api-env.json`）

### 2.2 运维/DBA
- **Microsoft SQL Server Management Studio (SSMS)**：≥19.4（仅Windows）
- **DBeaver CE**：≥24.0.0（跨平台），预配置公司数据库连接模板（含LDAP认证参数）
- **PuTTY / KiTTY**：≥0.78（Win），已内置公司跳板机配置（`jumpbox.company.local:2222`）
- **Ansible Tower CLI（awx-cli）**：≥22.10.0，配置`/etc/awx/cli.yml`指向公司AWX实例

## 三、常见报错与处理指南

### 3.1 安装阶段典型错误

| 错误码 / 现象 | 原因分析 | 解决步骤 |
|----------------|-----------|------------|
| `0x80070643`（M365安装失败） | Windows Update服务异常或组件损坏 | 1. 运行 `sfc /scannow`<br>2. 执行 `DISM /Online /Cleanup-Image /RestoreHealth`<br>3. 重启并重试SDP安装 |
| `Error: EACCES: permission denied, mkdir '/usr/local/bin'`（macOS Homebrew工具安装失败） | 用户无`/usr/local`写入权限 | 1. 执行 `sudo chown -R $(whoami) /usr/local`<br>2. `brew doctor`验证环境<br>3. 重新运行安装命令 |
| Zoom启动提示“Failed to initialize SSO” | Okta应用配置未同步或本地时间偏差 >5min | 1. 校准系统时间（`w32tm /resync` 或 `sudo ntpdate -u time.apple.com`）<br>2. 清除Zoom缓存目录（`%AppData%\Zoom` / `~/Library/Application Support/zoom.us`）<br>3. 重启Zoom并选择“Sign in with SSO” |

### 3.2 运行时高频问题（附日志定位路径）

- **Chrome 扩展无法加载（`ERR_BLOCKED_BY_CLIENT`）**  
  → 检查是否启用广告拦截插件冲突；查看 `chrome://extensions/` 中公司扩展状态；日志路径：`%LocalAppData%\Google\Chrome\User Data\Default\Extensions\{ext_id}\logs\`

- **SSMS 连接SQL Server报错 `Login failed for user 'NT AUTHORITY\ANONYMOUS LOGON'`**  
  → Kerberos双跳（Double-Hop）问题；需在AD中为SQL服务账户启用`Delegation`；验证命令：`setspn -L <sql_server_hostname>`

## 四、合规与审计要求

- 所有软件安装行为须记录于CMDB，字段包括：主机名、安装时间、版本号、安装源哈希值（SHA256）
- 每季度执行一次软件资产扫描（使用Lansweeper + 自定义PowerShell脚本），输出《终端软件合规报告》
- 禁止安装以下类型软件（列入黑名单）：
  1. 远程控制类（TeamViewer、AnyDesk，除非经IT安全书面批准）
  2. P2P下载工具（qBittorrent、uTorrent等）
  3. 未经签名的驱动程序或内核级软件（如某些录屏/录声工具）
