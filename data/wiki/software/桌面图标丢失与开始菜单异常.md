# 桌面图标丢失与开始菜单异常

## 问题现象

- 桌面图标全部消失（包括「此电脑」「回收站」「网络」等系统图标）  
- 开始菜单无法打开、点击无响应、空白、卡顿或仅显示「正在加载」  
- 开始菜单中应用列表为空，或搜索功能失效  
- 任务栏右键菜单异常（如缺少「任务管理器」「属性」等选项）

---

## 常见原因分析

| 类别 | 具体原因 | 说明 |
|--------|-----------|------|
| **用户配置损坏** | `Explorer.exe` 用户配置文件损坏 | `NTUSER.DAT` 或 `AppData\Local\Packages\Microsoft.Windows.StartMenuExperienceHost` 缓存异常 |
| **Shell 扩展冲突** | 第三方 Shell 插件（如旧版杀毒软件、美化工具）注册表项异常 | 导致资源管理器/开始菜单初始化失败 |
| **Windows 更新异常** | 累积更新（KBxxxxxx）安装不完整或回滚失败 | 尤其常见于 22H2 / 23H2 版本升级后 |
| **权限或策略限制** | 组策略禁用桌面图标（`User Configuration → Admin Templates → Desktop → Hide and disable all items on the desktop`）或开始菜单（`Start Menu and Taskbar` 策略） | 多见于公司域环境 |
| **系统文件损坏** | `shell32.dll`, `imageres.dll`, `StartMenuExperienceHost.exe` 等关键组件损坏 | 可通过 `sfc /scannow` 或 `DISM` 检测 |

---

## 排查与恢复步骤

### ✅ 步骤 1：重启 Windows 资源管理器
1. 按 `Ctrl + Shift + Esc` 打开任务管理器  
2. 在「进程」选项卡中找到 **Windows 资源管理器**（`explorer.exe`）  
3. 右键 → 「重新启动」  
   > ⚠️ 若该进程未列出，点击「详细信息」→ 查找 `explorer.exe`，右键结束进程后，点击「文件」→ 「运行新任务」→ 输入 `explorer.exe` → 回车  

### ✅ 步骤 2：检查桌面图标显示设置
1. 桌面空白处右键 → 「查看」→ 勾选「显示桌面图标」  
2. 若仍无图标，进入：  
   `设置 → 个性化 → 主题 → 桌面图标设置` → 勾选所需图标（如「此电脑」「回收站」）→ 「应用」

### ✅ 步骤 3：重置开始菜单体验宿主（StartMenuExperienceHost）
> 适用于 Windows 10 1809+ / Windows 11  
1. 打开 PowerShell（管理员）  
2. 依次执行以下命令：
```powershell
Get-AppXPackage -AllUsers | Foreach {Add-AppxPackage -DisableDevelopmentMode -Register "$($_.InstallLocation)\AppXManifest.xml" -Verbose}
```
3. 重启资源管理器（见步骤1）或重启系统

### ✅ 步骤 4：修复系统文件
在管理员 PowerShell 中执行：
```powershell
sfc /scannow
DISM /Online /Cleanup-Image /RestoreHealth
```
> ✅ 完成后重启。若提示 `sfc` 发现损坏但无法修复，需配合 `DISM` 使用离线源（如挂载 Windows ISO 的 `sources\sxs` 目录）

### ✅ 步骤 5：检查组策略与注册表（公司环境重点）
- 运行 `gpresult /h report.html` 检查是否启用如下策略：  
  - `User Configuration → Administrative Templates → Desktop → Hide and disable all items on the desktop`  
  - `User Configuration → Administrative Templates → Start Menu and Taskbar → Remove Classic Start Menu`  
- 注册表路径检查（谨慎操作）：  
  `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer`  
  确认 `NoDesktop`、`NoStartMenu`、`NoSetTaskbar` 等值为 `0` 或不存在

## 高级处理（仅限技术人员）

- **新建用户配置测试**：创建临时本地管理员账户，登录验证是否复现 —— 若正常，则原用户配置损坏，可迁移数据后重建用户  
- **安全模式排查**：启动至安全模式（按住 `Shift` + 重启 → 疑难解答 → 高级选项 → 启动设置 → 重启 → 按 `F4`），测试是否正常。若正常，说明第三方软件或驱动干扰  
- **事件查看器定位错误**：  
  `事件查看器 → Windows 日志 → 应用程序` & `系统`，筛选来源为：  
  - `Application Experience`（错误事件 ID: 1001）  
  - `ShellCommon`（ID: 1000+）  
  - `StartMenuExperienceHost`（ID: 101, 102）

## 常见错误代码参考

| 错误代码 | 含义 | 建议操作 |
|-----------|------|------------|
| `0x80073D02` | AppX 包注册失败（StartMenuExperienceHost） | 执行 `Add-AppxPackage -Register …` 或重装 `Microsoft.Windows.ShellExperienceHost` |
| `0x80070005` | 访问被拒绝（权限不足） | 检查当前用户对 `C:\Users\<User>\AppData\Local\Packages\Microsoft.Windows.StartMenuExperienceHost_*` 的完全控制权限 |
| `0xC0000005` | 访问冲突（explorer.exe 崩溃） | 使用 `ProcMon` 过滤 `explorer.exe` 的 `ACCESS DENIED` 或 `PATH NOT FOUND` 行为，定位异常 DLL |
